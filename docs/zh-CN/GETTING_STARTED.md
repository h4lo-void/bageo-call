# 开始使用

从零开始，直到 AI 接起第一通电话，再到 AI 第一次替你打电话。请预留大约一小时，大部分时间花在准备手机上。

## 1. 需要准备什么

- 一部**备用的 Android 手机**，插着能接电话的 SIM 卡，已经用 Magisk 或 KernelSU **root**，Android 10 及以上。在 Google Pixel 7、7a、8、9 上实测过。这里不讲怎么 root；请按你那个型号的教程操作，并记住解锁 bootloader 会清空手机。
- 一台**电脑**（Windows 10/11、Apple Silicon 或 Intel 的 macOS、Linux），需要接电话的时段要一直开着；还要一根连接手机的 USB 线。也可以用 Docker，手机改走 Wi-Fi。
- 一个 **Gemini API 密钥**：到 <https://aistudio.google.com/apikey> 登录，创建密钥并复制下来。Bageo 只需要这一个：实时通话、摘要、防诈复审、联系人导入都用它。Google 按用量计费；想设上限的话，可以在 Google 账号里设置预算。

## 2. 安装并启动主程序

“主程序”（agent）就是电脑上的那个程序：它和手机、Gemini 通信，保存通话记录，也提供网页控制台。它是单一程序，不需要数据库，也不用另外安装其他服务。

### 简单的方法：下载发布版

1. 从 [Releases](https://github.com/h4lo-void/bageo-call/releases) 页面下载适合你系统的安装包，解压到任意位置（例如 `Documents/bageo-call`）：`bageo-call-1.0.0-windows-x64.zip`、`-macos-arm64.tar.gz`（Apple Silicon）、`-macos-x64.tar.gz`（Intel）或 `-linux-x64.tar.gz`。每个安装包都包含主程序、内置音频、启动脚本和文档。
2. 启动：
   - **Windows：** 双击 `start.cmd`。如果 Windows SmartScreen 提示发布者未知，请选“更多信息 → 仍要运行”。
   - **macOS：** 双击 `start.command`。第一次运行时，macOS 可能会因为程序没有经过公证（notarize）而拒绝打开：请在 `start.command` 上右键 →“打开”；如果被拦下的是主程序本身，请到“系统设置 → 隐私与安全性”里允许它。也可以在终端里，于该文件夹执行一次 `xattr -dr com.apple.quarantine .`。
   - **Linux：** 在终端运行 `./start.sh`。
3. 脚本会查找 `adb`（Google 的 Android platform-tools，USB 连接需要它）。如果没有安装，脚本会询问是否从 Google 下载，放到程序旁边的 `platform-tools` 文件夹。
4. 浏览器会打开网页控制台 <http://localhost:8787/>。终端窗口请保持打开：把它关掉，主程序就停了。
5. 主程序第一次启动成功时，脚本会在桌面放一个“**Bageo 控制台**”快捷方式（macOS 是 `.webloc` 文件；Linux 是应用菜单里的条目，也会复制到桌面文件夹）。下次用它打开控制台就行。快捷方式还在就不会重新创建；不想要的话，启动时加 `-NoShortcut`（Windows）／`--no-shortcut`，或在 `.env` 设置 `BAGEO_NO_SHORTCUT=1`。改名前留下的“Myna 控制台”快捷方式也算数，旧的 `MYNA_NO_SHORTCUT=1` 照样有效。

### 从源码

```text
git clone https://github.com/h4lo-void/bageo-call.git
cd bageo-call
./start.sh            # Windows: .\start.cmd
```

装好 [Rust](https://rustup.rs) 之后，启动脚本第一次会先构建主程序（需要几分钟），然后启动。拉取新代码之后，加 `--build`（PowerShell：`-Build`）重新构建。

### 用 Docker

```text
cp .env.example .env        # 设置 CALLS_UI_TOKEN 和 DEVICE_TOKEN
docker compose up -d --build
```

在容器里，主程序是对局域网开放的，所以两个令牌都必须设置。控制台地址是 `http://<主机>:8787/?token=<CALLS_UI_TOKEN>`，手机通过 Wi-Fi 连接 `ws://<主机>:8787/ws?token=<DEVICE_TOKEN>`（见[手机设置 → Wi-Fi](PHONE.md#wi-fi)）。主程序在容器里不会响应 `bageo.local`，也无法自动填好通知链接用的控制台地址：请在 `.env` 里设置 `PUBLIC_URL`（例如 `http://192.168.1.20:8787`）。时区和从 Myna 旧名升级的做法，写在 `docker-compose.yml` 的注释里。

### 数据存在哪里

全部都在你启动程序的那个文件夹里（Docker 中是 `/data/calls`）：

| | |
|---|---|
| `data/calls/` | 通话记录、录音、文字记录、联系人、待处理事项、AI 代打记录 |
| `data/calls/config/settings.json` | 你在网页控制台里设置的内容，**包括你的 API 密钥** |
| `.env` | 可选的启动选项（端口、令牌）；见[设置参考](SETTINGS.md) |

`data/` 要备份还是删除都随你。不会保存到任何其他地方。

## 3. 填写基本设置

在网页控制台打开“设置”。

1. **语言**：AI 说话用的语言。“通知语言”可以不一样，例如 AI 用英语接电话，你看的通知保持简体中文。（控制台本身的显示语言，是页面顶部那个切换按钮。）
2. **你的名字**：来电的人怎么称呼你（“Alex”、“陈小姐”、“王先生”）。
3. **其他人怎么叫你**：一行一个，最多十个。英文名、昵称、简称（“Lex”）。AI 听到这些名字，就知道对方在找你。
4. **接听身份**
   - “AI 助理”：“您好，这里是 Alex 的 AI 助理，他现在不方便接电话，请问有什么需要我转达的吗？”对来电者很清楚，在法律上也是更稳妥的选择。
   - “本人”：AI 按你的方式说“喂？”，以你的身份说话。它不会替你做任何承诺，有人认真问起时也会承认自己是 AI，但来电的人通常会以为就是你。请先读[隐私、安全与法律](PRIVACY_AND_LEGAL.md)。
5. **Gemini API 密钥**：粘贴并保存。摘要默认也用同一个密钥（Gemini 最便宜的模型）；只有在“摘要服务”里选了其他服务（例如 DeepSeek、OpenRouter 或本机的 Ollama）时才需要另一个密钥。
6. **声音**：按列表旁边的 ▶，听每个声音用你的语言说几句话。这些示例随程序内置，不产生任何费用。

保存。“系统”页的检查清单会列出还缺什么。

## 4. 准备手机

详细说明和还原方法：[手机设置](PHONE.md)。简单来说：

1. 把发布版附带的 `pixelcallai_uplink-<version>.zip` 复制到手机，在 Magisk 或 KernelSU 应用里安装为模块。重启。
2. 打开 **Bageo** 应用，把“设置步骤”逐项点完，直到每一项都显示 OK（权限、默认电话应用、来电筛选、勿扰权限、电池优化豁免）。应用本身不需要 root 权限，这些事由模块完成。
3. 开启 **USB 调试**（“设置 → 关于手机”→ 连续点“版本号”七次，再到“系统 → 开发者选项 → USB 调试”）。
4. 把手机插到电脑上。在手机上的**“允许 USB 调试吗？”**里点允许，并勾选“始终允许使用这台计算机进行调试”。

大约十五秒内，主程序会自动建好 USB 连接，并启动应用的通话服务。网页控制台的“系统 → 手机”会显示这部手机，先是“已插入”，接着是“已连接主程序”。

> 这部手机现在是一台接电话的设备：它不会响铃出声，原来的电话应用被隐藏，通话时麦克风和扬声器都保持静音，房间里的声音不会被听到。这是有意设计的。想暂时当普通手机用，在“系统 → 手机”或应用里切换到[普通手机模式](PHONE.md#普通手机模式)，随时都能切回来。

## 5. 第一通电话

用另一部手机拨打这部手机的号码。

- 对方那边会响一声（大约三秒，可以调整）。这一声的时间里，AI 已经连上并准备好第一句话。
- AI 接起来。跟它聊、打断它、用另一种语言问它问题，然后说再见。
- 通话结束几秒后，它会出现在“通话”里，附带录音（整通、只有对方、只有 AI）、文字记录和四行摘要：对方、事情、AI 回复、要处理。用其他语言说的句子保留原文，下面附上翻译。

如果没人接，请看[故障排查](TROUBLESHOOTING.md)；“系统”页通常会告诉你缺了哪一环。

## 6. 通知

“设置 → 通知 → 添加渠道”，选一个服务，填好字段（每个字段都有获取方法的提示），按“**发送测试**”。可以添加多个，每条消息都会发到所有渠道。一共支持 16 种服务，从 Telegram（预约卡片带“同意／不同意”按钮）到自定义 webhook。各服务的配置方法：[通知](NOTIFICATIONS.md)。

想让通知里的链接能打开那通电话，请把控制台对局域网开放，见[从其他设备使用控制台](SETTINGS.md#从其他设备使用控制台)。之后链接会指向 `http://bageo.local:8787/`（主程序能响应这个名称时），否则指向电脑的局域网地址；“系统 → 关于”会显示当前用的是哪一个，并附二维码。只有在你通过其他方式访问这台电脑时（VPN 名称、反向代理、Docker），才需要设置“这个控制台的地址”。

在你的手机上：先在电脑的控制台里打开“系统”，“关于”会显示控制台地址和二维码。用手机扫描，再把页面添加到主屏幕（iPhone：“分享 → 添加到主屏幕”；Android：Chrome 菜单 ⋮ →“添加到主屏幕”）。之后点 Bageo 图标就能打开。

## 7. 联系人、日程预约与 AI 代打

接电话用不到这些功能，每一项设置都只要几分钟。

### 联系人

到“联系人 → 导入”，拖入一个文件：从手机导出的 vCard（`.vcf`）、Google 通讯录或 Outlook 的 CSV、保存为 CSV 或 TSV 的表格、Excel `.xlsx` 或 Word `.docx` 里的表格、每行一个名字加号码的纯文本，或者 PDF、名片照片、通讯录截图（由 Gemini 识别）。保存前每一条都会先给你看，重复的可以选择合并或跳过。联系人的备注（“我妹妹”“房东”）会在这个人打来时放进 AI 的提示词。也可以在某通电话的详情里按“**加入联系人**”。

### 日程预约

“设置 → 摘要与日历 → 日程预约 → 先问我”即可开启。来电的人想约时间时，AI 会说确认一下再回复；通话结束后，这条预约会出现在“通话”页最上方的“**待处理事项**”里。选好怎么告诉对方（**发短信**、**AI 回拨**或**不通知对方**），再按“**同意**”或“**不同意**”。要发短信的话，得先打开“发短信告诉对方”。第一次在同意的预约上按“**添加到日历**”时，选择你用的日历（Google、Outlook.com、Microsoft 365、Apple、Yahoo 或 `.ics`），之后按下去就直接添加。

### 第一次 AI 代打

手机得先接过至少一通电话，主程序才知道它插的是哪张 SIM 卡。然后打开“**AI 代打**”：

1. 在“打给谁”输入联系人名字或号码。不带 `+` 的号码视为你所在国家的号码；国外号码请以 `+` 开头。AI 只会用和号码同一国家的 SIM 卡拨打。
2. 在“要处理的事”里写清楚要办什么、哪些条件可以接受，例如：“订明天晚上 7 点 4 位，姓王，无烟区；7 点没位子的话 7 点半到 8 点也行。”
3. 选择“用什么身份打”：你的助理（默认）或你本人。
4. 开始拨打，并保持页面打开。你会看到实时字幕；AI 拿不准时，会弹出一张 40 秒倒计时的提问卡问你，“告诉 AI”也能随时交代它。

结果会出现在交办列表里，并只发一条通知。结果显示“要你决定”时，从选项里挑一个或自己写回复，再请 AI 打一次。

## 8. 让它一直运行

主程序要一直运行，才接得到电话。

- **Windows：** 把 `start.cmd` 的快捷方式放进“启动”文件夹（`Win+R` → `shell:startup`），或在“任务计划程序”里创建一个“登录时”运行 `start.cmd -NoBrowser` 的任务。插电时请关闭睡眠。
- **macOS：** “系统设置 → 通用 → 登录项”→ 添加 `start.command`；并防止睡眠（“电池／节能 → 防止自动进入睡眠”）。
- **Linux：** 创建一个 systemd 用户服务：

  ```ini
  # ~/.config/systemd/user/bageo-call.service
  [Unit]
  Description=Bageo agent
  After=network-online.target

  [Service]
  WorkingDirectory=%h/bageo-call
  ExecStart=%h/bageo-call/start.sh --no-browser --yes
  Restart=on-failure

  [Install]
  WantedBy=default.target
  ```

  运行 `systemctl --user enable --now bageo-call` 和 `loginctl enable-linger $USER`，让它在没有登录会话时也能运行。
- **Docker：** `docker-compose.yml` 里的 `restart: unless-stopped` 已经会在重启后把它拉起来。

手机请一直连着充电器。手机或电脑重启的话，两边都会自动重新连接。
