# 路线图

对照大家对开源电话接听系统的期待，这个项目目前做到了哪一步，以及接下来值得做什么。这里没有任何一项是承诺；欢迎提交 pull request。

## 这个项目有什么不同

大多数开源的接待系统都需要 SIP 中继或云电话服务账号。这个项目接的是**你本来就有的那张 SIM 卡**，用你桌上的一部手机，配合语音到语音（speech-to-speech）模型——所以不用租号码，延迟和插话处理都由模型本身负责，而不是靠语音转文字、LLM、文字转语音一环一环串起来。

## 社区想要的功能——当前状态

| 需求 | 状态 |
|---|---|
| 全天候接听、自由对话而不是菜单 | ✅ |
| 低延迟 | ✅ 语音到语音；手机还在响的时候就先准备好开场白。 |
| 真正的打断（barge-in） | ✅ 在通话录音里不含 AI 自己声音的手机上（我们实际使用的 Pixel 9）；在其他手机上，AI 会先把一句话说完。 |
| 沉默处理 | ✅ 先问对方还在不在，然后结束通话。 |
| 语音活动检测、噪声 | ✅ 用 Gemini 的，或者本地的检测器。 |
| 语言检测、通话中切换 | 🟡 每通都会跟着对方的语言换；依赖模型本身。 |
| 多种语言、本地化的提示词 | 🟡 九种语言；只有繁体中文在真实通话中验证过。 |
| 方言和口音 | 🟡 模型能听懂什么就是什么；我们没有另外调校。 |
| 骚扰电话／自动语音电话处理 | ✅ 拦截号码；推销和诈骗电话通过关键词检测，然后婉拒或陪聊拖时间。 |
| 基于知识库回答、不瞎编 | 🟡 “AI 可以回答的资料”——放在提示词里的纯文本，加上一条“不要猜”的规则。没有文档检索。 |
| 来电者记忆（认出再次打来的人） | ❌ |
| 通话后摘要、意图、待办 | ✅ 四行。没有情绪分析或数据看板。 |
| 日历 | 🟡 带“添加到日历”链接／`.ics` 的建议；可选自动添加到 Google 日历。AI **不会**在通话中预约时间。 |
| 通知、短信／电子邮件摘要 | ✅ 十六种渠道类型，包括电子邮件。不发送短信。 |
| Webhook、n8n / Zapier | ✅ 每个事件一个 JSON webhook；其余的用 REST API。 |
| 描述你的业务、自动完成配置 | 🟡 访谈提示词，在任意聊天 AI 里运行。 |
| AI 身份披露、录音告知 | 🟡 “AI 助理”方式内置披露；“本人”方式在被问到时强制披露。录音告知要靠你的提示词。 |
| 抵御提示词注入 | 🟡 每份提示词里都有一条固定规则；没有单独的过滤器。 |
| 自带密钥、没有按分钟计费的平台费 | ✅ |
| 所有东西都保存在自己的机器上 | ✅ 除了发给模型和通知服务的部分。 |
| 网页控制台 | ✅ |
| 一步启动 | ✅ Windows / macOS / Linux 的启动脚本；Docker 镜像。 |
| REST API | ✅ — MCP ❌ |
| 营业时间、节假日 | ❌（简单的情况可以用状态留言应付） |
| VIP 号码直接转给真人 | ❌ |
| 带摘要转接给真人 | ❌ 手机应用目前还不能桥接通话。 |
| 来电者和真人之间的实时翻译 | ❌ |
| 紧急关键词处理 | ❌ |
| 花费上限、每日通话数限制 | ❌ 只有最长通话时间的设置；请到你的 API 提供商那里设置预算。 |
| 完全本地的语音技术栈（Whisper / Ollama / Piper） | ❌ 受支持的模式下没有。代码里有一条较旧的流水线，但无人维护。摘要已经可以使用本地模型。 |
| SIP / Asterisk / FreeSWITCH | ❌ 不是目标——但手机协议很小而且有文档，所以可以用 SIP 前端来代替手机。 |
| 多租户、白标 | ❌ 没有计划。 |
| CRM 集成 | ❌ 请用 webhook。 |

## 值得做的下一步

大致按“花的功夫能换来多少用处”排序：

1. **来自其他手机和其他语言的反馈**——哪些能用、哪些不能。这比任何功能都重要。
2. **按号码设置规则**：给已知来电者加上名字和备注（“这是我妈妈”）、一定会响亮通知的 VIP、永远不陪聊拖时间的号码。
3. **来电者记忆**：把同一个号码最近几次的摘要放进提示词。
4. **营业时间**：非营业时间改用另一份提示词，或者播放一段语音。
5. **通话中使用工具**（Gemini function calling）：查日历、查订单。需要谨慎——能行动的 AI，也可能做错事。
6. **通话转接／多方通话**：由手机应用来做，让真人可以接手。
7. **其他实时模型**：接在同一套通话逻辑后面（OpenAI Realtime，以及日渐成熟的本地语音到语音模型）。
8. **移除较旧的菜单式代码路径**，让主程序更容易读。
9. **经过签名和公证的发行版**（macOS 和 Windows）。
