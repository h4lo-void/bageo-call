# 路线图

Bageo 1.6 这套开源 AI 电话助理已经做到了哪些、哪些只做到一部分，以及接下来值得做什么。这里没有任何承诺或时间表；欢迎提交 pull request。

## Bageo 跟其他 AI 总机有什么不同

大多数开源 AI 总机都需要 SIP 中继或云通信账号。Bageo 接的是**你本来就有的 SIM 卡**，插在你桌上一部已 root 的 Android 手机里，配合语音对语音模型（Gemini Live）：不用另外租号码，回话快、能被插话靠的是模型本身，而不是语音转文字、LLM、文字转语音串起来的一条链。从 1.0 开始，同一部手机也能用你自己的号码替你打电话。

## 1.6 的现状

**已完成**：现在就能用。**部分**：能用，限制写在说明栏。**还没有**：尚未实现，没有时间表。

### 接听来电

| 需求 | 现状 | 说明 |
|---|---|---|
| 全天候接听，自由对话而不是按键菜单 | 已完成 | |
| 低延迟 | 已完成 | 语音对语音；手机还在响时就准备好开场白（实测从接起算中位数约 0.43 秒）。 |
| 真正的插话（barge-in） | 已完成 | 在收音不含 AI 自己声音的手机上（例如 Pixel 9）每通电话自动检测；其他手机上 AI 会先说完那一句。 |
| 静默处理 | 已完成 | 先问对方还在不在，再结束通话。 |
| 语音检测、噪声 | 已完成 | 用 Gemini 自带的检测，或本地检测器。 |
| 自然的环境感 | 已完成 | 12 种背景音、三档音量。 |
| 拦截骚扰、诈骗与机器人电话 | 已完成 | 黑名单（可用 `*` 拦同一个开头）；三道防线（回复白名单、加权关键词、语义复审），再选礼貌拒绝或陪聊模式。 |
| 认出常打来的人 | 部分 | 通讯录让 AI 知道来电者的名字和你的备注。同一号码之前的摘要还不会放进提示词。 |
| 按知识库回答、不乱编 | 部分 | “AI 可以回答的资料”：放在提示词里的纯文本，加上“不要猜”的规则。没有文档检索。 |
| 披露 AI 身份、录音告知 | 部分 | “AI 助理”方式内置披露，“本人”方式以你的身份说话、不主动或被问时表明是 AI。录音告知要写在你的提示词里。 |
| 防提示词注入 | 部分 | 每份提示词都有固定规则；没有单独的过滤器。 |

|---|---|---|

| 识别语言、通话中切换 | 已完成 | 开场由来电号码和 SIM 卡决定；通话中 AI 跟着对方换语言。用说 28 种语言的来电者模拟过。 |

| 文字记录翻译 | 已完成 | 其他语言的句子保留原文，附上翻译成你通知语言的对照。 |
| 方言与口音 | 部分 | 模型听得懂多少就是多少；没有额外调整。 |
| 来电者与真人之间的实时翻译 | 还没有 | |

### 替你办事

| 需求 | 现状 | 说明 |
|---|---|---|
| 替你拨出电话 | 已完成 | AI 代打：实时字幕、向你提问（`ask_owner`）、通话中补充交代、结构化结果、接续再打。已在模拟中验证；欢迎反馈真手机上的使用结果。 |
| 预约时间 | 已完成 | AI 记下请求但不当场答应；你在“待处理事项”或 Telegram 卡片上同意或不同意；对方通过短信或 AI 回拨收到答复。 |
| 日历 | 已完成 | 一键添加到 Google、Outlook.com、Microsoft 365、Apple、Yahoo 或 `.ics`，不用连接任何日历账号。 |
| 短信回复 | 已完成 | 预约答复从接那通电话的 SIM 卡用短信发出。收到的短信可以用短信转发工具转出去，也能在控制台的“**短信**”页直接查看对话并回复。 |
| 通讯录 | 已完成 | 导入 vCard、CSV、TSV、纯文本、Excel、Word，PDF 和图片交给 Gemini 识别；合并重复；导出 vCard。 |
| 通话中使用工具 | 部分 | `propose_appointment` 与 `ask_owner`，各自受严格的状态机管控。有意不开放任意工具。 |
| 通话摘要、意图、待办 | 已完成 | 四行摘要，预约变成待处理事项。没有情绪分析或统计仪表盘。 |

## 接下来值得做的

大致按“投入换来的效益”排序：

1. **真实使用的反馈**：AI 代打在真手机上拨出、其他手机型号、其他语言、Telegram 以外的通知渠道。这比任何新功能都重要。
2. **来电记忆**：除了联系人名字和备注，把同一号码最近几次的摘要放进提示词。
3. **按号码的规则**：一定大声通知的白名单号码、绝不陪聊的号码、特定联系人用不同的提示词。
4. **营业时间**：时间外改用不同提示词或播放一段语音。
5. **手机报告更清楚的通话状态**：拨出的电话被接起的那一刻就报告，让“待处理事项”和代打页面不用靠听人声，就能分辨“已接通”和“还在响”。
6. **完善通话转接与三方通话**，让试验中的急事三方通话更稳定，并增加附语音摘要的暖转接。
7. **同一套通话逻辑换用其他实时模型**（OpenAI Realtime，以及逐渐成熟的本地语音对语音模型）。
8. **移除旧的菜单式代码路径**，让 Bageo 的代码更易读。
9. **macOS 与 Windows 的签名、公证发布版**。
