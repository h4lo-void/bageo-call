# 手机设置

手机是通往电话网络的网关：它插着你的 SIM 卡，悄无声息地接起来电，把对方的声音发给主程序，再把 AI 的声音播放到通话里。它本身不做任何 AI 运算。

关于构建应用、它的权限和通信协议，全部写在 [`android/README.md`](../../android/README.md)（英文）里。这一页是从用户的角度来讲的。

## 支持哪些手机

- **实测过：Google Pixel 7、7a、8、9**，用 Magisk 或 KernelSU root。
- **其他手机：风险自负。** 应用需要手机的音频硬件层提供两样东西，而很多手机并不向应用开放，即使是特权应用也不行：在通话中录下对方的声音，以及把声音播放“进”通话里。只要缺一样，电话会被接起来，但有一方什么都听不到。目前还没有其他可用机型的列表——如果你试了，请反馈结果。
- Android 10 或更高版本。

有一项行为因手机而异，主程序会在每通电话开始时自行判断。如果手机的通话录音里不包含 AI 自己的声音（我们实际使用的 Pixel 9），对方可以在 AI 说话时插话，背景音也会贯穿整通电话。如果包含（我们实际使用的 Pixel 7 和 7a），AI 自己的声音会从它听到的内容里滤掉，所以它会先把一句话说完再继续听，背景音也只在 AI 说话时播放。

## 请用备用手机

安装模块之后，手机会变成一台专门接电话的机器：

- 应用会成为默认电话应用和来电过滤应用，Google 的电话应用会被停用（不会出现通话界面）；
- 勿扰模式会开启，铃声和通知音量调为零；
- 通话过程中麦克风静音、扬声器关闭、听筒音量调到最小——房间里的声音不会被听到，也不会有任何声音外放。

你仍然可以用另一个拨号应用从这部手机打电话出去，但别指望它像普通手机那样好用。以上这些都可以在应用或网页控制台里关掉（见[普通手机模式](#普通手机模式)），也可以彻底撤销（见[还原](#还原)）。

## 安装

1. 给手机 **root**（Magisk 或 KernelSU）。这里不讲。
2. 如果你曾经把这个应用当作普通 APK 安装过，请先卸载。绝对不要两种同时存在。
3. 把 `pixelcallai_uplink-<version>.zip` 复制到手机上，打开 Magisk 或 KernelSU 应用 →“模块”（Modules）→“从本地安装”（Install from storage）→ 选择那个 zip → 重启。
4. 打开 **Myna**。最上面的卡片用一句话说明手机现在的状态。下面的“**设置步骤**”列出还没完成的事，每一步都有一个按钮：

   | 步骤 | 要做什么 |
   |---|---|
   | 安装 Myna 模块 | 重启后就会完成。如果没有，说明模块没有生效。 |
   | 允许 Myna 使用电话和麦克风 | “**允许**”（麦克风、电话、通话记录、通知）。 |
   | 把 Myna 设为默认电话应用／来电过滤应用 | “**设置**”。 |
   | 允许 Myna 控制勿扰模式 | “**打开设置**”并允许。 |
   | 不要让 Myna 进入休眠 | “**允许**”，Android 才不会把服务停掉。 |

   Root 管理器询问时，请允许 root。步骤全部完成后列表会自动收起；手机连上电脑后，卡片会显示“AI 正在帮你接电话”。连接地址、测试连接和详细检查都在“**高级**”里。
5. 让“**AI 帮我接电话**”保持开启。

## 连接到电脑

### USB（推荐）

1. 在手机上：“设置 → 关于手机 →”连点“版本号”七次；然后到“系统 → 开发者选项 →”开启 **USB 调试**。
2. 把手机插到运行主程序的那台电脑上。
3. 在手机上的“**允许 USB 调试吗？**”弹窗里点允许（勾选“一律允许”）。

这样就行了。主程序会找到手机，把应用的本地地址（`ws://127.0.0.1:8765`）通过 USB 线映射到自己这边，并启动应用的服务。它每十五秒检查一次，所以拔掉再插上、或者任何一边重启，都会自动恢复。USB 还能让手机保持充电，没有 Wi-Fi 也能用。

一台电脑可以插好几部手机；每部手机各自接听自己的号码。

### Wi-Fi

手机没办法用线连到电脑时，才用这种方式。

1. 启动主程序时，让它在网络上监听并要求令牌：在 `.env` 里设置 `AGENT_HOST=0.0.0.0`、`DEVICE_TOKEN=<a long random string>` 和 `CALLS_UI_TOKEN=<another one>`（两个各填一长串不同的随机字符；见[设置参考](SETTINGS.md)）。
2. 在应用的“高级 → 连接”里输入 `ws://<computer's address>:8787/ws?token=<DEVICE_TOKEN>`（其中 computer's address 换成电脑的地址），然后保存。“**测试连接**”会告诉你能不能连上；连不上时会用大白话说明原因，原始错误信息在“详细信息”里。

这个连接没有加密（`ws://`）：只能在你自己的网络里使用，或者在前面架一个 TLS 反向代理并改用 `wss://`。通话走 USB 更稳定。

## 日常使用

- 服务运行时，应用会显示一条不打扰的常驻通知；重启后也会自动启动。
- 想暂时自己用这部手机，就把它切成[普通手机](#普通手机模式)。想让所有手机的 AI 一起停，在网页控制台里关掉“由 AI 接听来电”（电话会被接起来再挂断）。
- 你自己用这部手机拨出去的电话，应用不会介入。
- 主程序知道控制台地址后（设置里的“这个控制台的地址”），应用里会出现“**打开网页控制台**”按钮。

## 普通手机模式

手机有两种模式，除了通话中以外随时可以切换：

- **AI 帮我接电话**（默认）：就是[请用备用手机](#请用备用手机)里说的接管状态。从没切换过的手机，更新后也保持这个模式。
- **普通手机**：来电正常响铃，由你自己接。AI 不接、没有东西被静音，Google 的电话应用也回来了。

**在手机上切换：** 打开 Myna，把最上面的大开关“**AI 帮我接电话**”关掉或打开。确认后等几秒，卡片就会显示“普通手机：来电会正常响铃”（或 AI 又开始接电话）。

**在网页控制台切换：** “系统 → 手机”。每部已连接的手机会显示名称、应用版本、当前模式和一个按钮：“**改成普通手机**”或“**改回 AI 接听**”。改成普通手机前会先弹出确认框。应用版本早于这个功能的手机，会显示“这部手机的 Myna 应用需要更新，才能从这里切换”，没有按钮。

切成**普通手机**会依次改这些系统设置：

1. Myna 不再是来电过滤应用，来电不会再被静音。
2. 关掉勿扰模式。
3. 铃声模式改回正常；铃声、通知、听筒、媒体、闹钟、系统音量恢复成这部手机上次切到 AI 模式前的数值。没保存过、或保存的是 0 的，就用最大值的一半。
4. 麦克风不再被静音，听筒音量也不再被固定在最小。
5. 最后才重新启用 Google 电话（`com.google.android.dialer`），并设为默认电话应用。没有 Google 电话的手机，Myna 会把这个角色让出来，由 Android 使用手机自带的电话应用。要确认 Google 电话真的成了默认电话应用、而且没有被停用，这次切换才算完成。

这些设置由一个 root 脚本来改。Android 在拿走电话应用角色时可能会把 Myna 关掉，脚本照样会跑完，所以换电话应用放在最后一步。

Myna 的服务会继续运行、保持连接，方便你从网页控制台切回来，但它不会接、不会静音、也不会碰任何一通电话。网页控制台会把这部手机显示为普通手机，`/health` 的 `normal_mode_serials` 也会列出它。

切回“**AI 帮我接电话**”时，会先把当前音量保存起来，再重做一次模块的接管：Myna 成为电话应用和来电过滤应用、停用 Google 电话应用、打开勿扰、音量归零。

切换做到一半失败时，应用和网页控制台都会说明是哪一步没成功（例如“无法更换默认电话应用”）。再切一次会把每一步重做一遍；切换还没完成时，应用下次启动（例如重启后）也会自己重做。切换需要 root，Root 管理器询问时请允许。网页控制台 15 秒内没收到手机回复时，会显示“结果未确认，请稍后刷新”，稍后刷新就能看到手机报告的模式。

如果你用过 0.2.2 以前的版本、而且当时把“AI 接听”开关关掉了：那个设置已经不算数，更新后这部手机会由 AI 接电话，状态卡上也会有一行提示。要继续当普通手机，请把“**AI 帮我接电话**”关掉。

模式保存在 `/data/adb/pixelcallai/mode`（内容是 `ai` 或 `normal`），在模块文件夹外面，所以重启、更新模块都不会丢。模块每次开机都会读取它；文件不存在就是 AI 模式。普通手机要恢复的音量保存在 `/data/adb/pixelcallai/normal_audio`，上一次切换的结果在 `last_apply`，切换还没完成时会有 `pending` 这个文件。

不通过应用界面、用电脑的 `adb` 切换：

- 不用重启（应用会一次把整个切换做完）：

  ```text
  adb shell am start-foreground-service -n com.pixelcallai.streamer/.CallAudioService -a com.pixelcallai.streamer.SET_ENABLED --ez enabled false
  ```

  改成 `--ez enabled true` 就切回“**AI 帮我接电话**”。
- 写入模式文件再重启（应用的服务启动时会把其余设置补上）：

  ```text
  adb shell "su -c 'mkdir -p /data/adb/pixelcallai && echo normal > /data/adb/pixelcallai/mode'"
  adb reboot
  ```

  切回 AI 模式：改写成 `ai`（`echo ai > …`），或用 `adb shell "su -c 'rm -f /data/adb/pixelcallai/mode'"` 删掉这个文件，再重启。

## 还原

**要装回旧版 Myna（0.2.2 以前的任何版本）之前**，先把手机切回“**AI 帮我接电话**”，或删掉状态文件夹：`adb shell "su -c 'rm -rf /data/adb/pixelcallai'"`。旧版不认识模式文件：它的模块每次开机都会重新接管手机，模式文件写着 `normal` 也一样。等你以后再装回这个版本，它会在模式文件里看到 `normal`，自己把手机切成普通手机，AI 就在没人要求的情况下停止接电话。

1. 先把手机切成[普通手机](#普通手机模式)。这会恢复 Google 的电话应用、铃声和音量，并关掉勿扰，第 3、4 步就不用做了。
2. 在 Magisk / KernelSU 里停用或移除 **Myna Uplink** 模块，然后重启。如果手机启动不到那一步，请使用 root 管理器的安全模式，或者在 recovery 里以 root 身份运行：`touch /data/adb/modules/pixelcallai_uplink/disable`。模式文件所在的 `/data/adb/pixelcallai/` 会保留；以后不打算再装 Myna 的话，把这个文件夹也删掉。
3. 如果没先切换就移除了模块：移除模块**不会**把 Google 的电话应用恢复回来，也不会关掉勿扰模式——这些 Android 都会记住。重新启用电话应用：

   ```text
   adb shell su -c "pm enable com.google.android.dialer"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallServiceImpl"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallActivity"
   adb shell su -c "cmd role add-role-holder android.app.role.DIALER com.google.android.dialer"
   adb shell su -c "telecom set-default-dialer com.google.android.dialer"
   ```

4. 到系统设置里关掉勿扰模式，并把音量调回来。
