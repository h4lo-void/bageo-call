# 手机设置：把 root 过的 Android 手机变成 AI 接电话专用机

手机是 Bageo 通往电话网络的那条线。它插着你的 SIM 卡，静默接起来电，把对方的声音实时发给电脑上的主程序，再把 AI 的声音播回通话里。AI（Gemini Live）由主程序负责，手机本身不做任何 AI 运算。这一页说明哪些手机能用、怎么安装 root 模块、用 USB 或 Wi-Fi 连接电脑、在 AI 接听和普通手机之间切换，以及怎么全部还原。

构建应用、它的权限和通信协议，写在 [`android/README.md`](../../android/README.md)（英文）里。

这一页说明的是 **Bageo 1.0**：root 模块 `v1.0.0`（versionCode 20），里面的应用是 `1.0.0`（versionCode 28），安装包是 `pixelcallai_uplink-1.0.0.zip`。应用的版本在它的“高级”页面能看到，网页控制台则在“系统 → 手机”里。

## 手机会做哪些事

| 工作 | 怎么做 |
|---|---|
| 静默接听来电 | 按主程序要求的时间让电话响（默认 3 秒），静默接起，在通话和主程序之间来回传送双方的声音。手机旁边的人两边都听不到。 |
| 在 AI 接听和普通手机之间切换 | 应用里一个开关，或网页控制台里一个按钮。系统设置由模块的 root 助手来改，应用本身不需要 root 权限。见[普通手机模式](#普通手机模式)。 |
| 不碰你自己打的电话 | 你在手机上自己拨出的电话不会接入 AI，麦克风和听筒照常能用；挂断后手机会重新静音。只有打进来的电话，和主程序要求拨出的电话（AI 回拨、AI 代打）才会接入 AI。 |
| 替你发短信 | 你回复日程预约、选择用短信通知时，由接那通电话的手机用自己的号码发出（`send_sms`）。 |
| 替主程序拨电话 | 告诉对方预约结果的 AI 回拨，以及你在网页控制台“AI 代打”页交办的电话（`place_call`）。手机在响铃或通话中时不会拨号：新的电话会等它空闲下来（代打最多等 10 分钟）。 |
| 选对 SIM 卡 | 双卡手机发短信、打电话时，用主程序指定的 Android 订阅 id（`sub_id`）那张卡：原来那通电话打进来的卡；代打则用与号码同一国家的卡。 |
| 一次只接一通 | 通话中又有第二通打进来，会立即拒接（对方听到忙音），并上报主程序（`call_waiting_rejected`）。通话列表会留下记录，你也会收到“通话中插播未接”通知。 |
| 出问题时安全收场 | 响铃时连不上主程序：不接，交给运营商按未接来电处理或转语音信箱。通话中与主程序断开 3 秒：直接挂断，不让对方对着一片安静。 |

## 支持哪些手机

- **实测过：** Google Pixel 7、7a、8、9，用 Magisk 或 KernelSU root。
- **Android 10 或更高版本。**
- **其他手机：风险自负。** 应用需要手机开放两样东西，很多手机连特权应用都不给：通话中录下对方的声音，以及把声音播放“进”通话里。缺一样，电话会被接起来，但有一方什么都听不到。目前还没有其他可用机型的列表；如果你试了，欢迎反馈结果。

不同手机还有一项差异，主程序会在每通电话开始时自己检测：手机的通话录音里，会不会录到 AI 自己的声音。

| 通话录音 | 会有什么不同 | 实测机型 |
|---|---|---|
| 录不到 AI 的声音 | AI 说话时对方可以插话，背景音贯穿整通电话。 | Pixel 9 |
| 录得到 AI 的声音 | AI 会把自己的声音从听到的内容里滤掉，所以它会先把一句话说完再继续听，背景音也只在 AI 说话时播放。 | Pixel 7、7a |

## 请用备用手机

装好模块后，手机就成了一台接电话专用机：

- Bageo 成为默认电话应用和来电过滤应用，Google 的电话应用被停用，所以不会出现通话界面。
- 勿扰模式打开，铃声和通知音量调为零。
- 通话时麦克风静音、扬声器关闭、听筒音量调到最小：房间里的声音不会被收进去，也不会有声音外放。

你仍然可以用别的拨号应用打电话出去，但它已经不适合当日常手机。以上这些都能在应用或网页控制台里关掉（见[普通手机模式](#普通手机模式)），也能彻底还原（见[还原](#还原)）。

## 安装

1. 用 Magisk 或 KernelSU 给手机 **root**（这里不讲）。
2. 如果你曾经把这个应用当作普通 APK 安装过，请先卸载。两种绝对不要同时存在。
3. 把 `pixelcallai_uplink-<version>.zip` 复制到手机（这一版是 `pixelcallai_uplink-1.0.0.zip`）。在 Magisk 或 KernelSU 应用里：“模块”（Modules）→“从本地安装”（Install from storage）→ 选择那个 zip → 重启。
4. 打开 **Bageo**。最上面的卡片用一句话说明手机现在的状态。下面的“**设置步骤**”列出还没完成的事，每一步都有按钮：

   | 步骤 | 要做什么 |
   |---|---|
   | 安装 Bageo 模块 | 重启后就会完成。没有的话，说明模块没有生效。 |
   | 允许 Bageo 使用电话和麦克风 | 点“**允许**”（麦克风、电话、通话记录、通知）。 |
   | 把 Bageo 设为默认电话应用／来电过滤应用 | 点“**设置**”。 |
   | 允许 Bageo 控制勿扰模式 | 点“**打开设置**”并允许。 |
   | 不要让 Bageo 进入休眠 | 点“**允许**”，Android 才不会把服务停掉。 |

   应用本身不需要 root 权限（root 的工作由模块做），所以 root 管理器如果询问，允许或拒绝都可以。步骤全部完成后列表会自动收起；手机连上电脑后，卡片会显示“AI 正在帮你接电话”。连接地址、测试连接和详细检查都在“**高级**”里。

   设置页面不会向你要发短信的权限（`SEND_SMS`）：模块会在开机时、以及每次切换到 AI 模式时授予。双卡手机选择 SIM 卡一律用订阅 id，不比对卡片自己的号码，所以也不需要其他权限。
5. 让“**AI 帮我接电话**”保持开启。

### 更新

用同样的方式（“从本地安装”）把新的 zip 装在旧模块上，然后重启。你选的模式、连接地址和应用的权限都会保留。本仓库发布的版本都用项目自己的密钥签名，可以直接覆盖安装；如果要在发布版和自己构建的版本之间切换，请先移除模块并重启（见 [`android/README.md`](../../android/README.md#build)，英文）。

## 连接到电脑

### USB（推荐）

1. 在手机上：“设置 → 关于手机”，连续点“版本号”七次；再到“系统 → 开发者选项”开启 **USB 调试**。
2. 把手机插到运行主程序的那台电脑上。
3. 在手机上的“**允许 USB 调试吗？**”弹窗里点允许（勾选“始终允许”）。

这样就行了。主程序会找到手机，把应用的本地地址（`ws://127.0.0.1:8765`）通过 USB 线映射到自己这边，并启动应用的服务。它每 15 秒检查一次，所以拔掉再插上、或者任何一边重启，都会自动恢复。USB 还能让手机一直充电，没有 Wi-Fi 也能用。一台电脑可以插好几部手机，每部各自接听自己的号码。

### Wi-Fi

手机没办法用线连到电脑时，才用这种方式。

1. 让主程序在网络上监听并要求令牌：在 `.env` 里设置 `AGENT_HOST=0.0.0.0`、`DEVICE_TOKEN=<一长串随机字符>` 和 `CALLS_UI_TOKEN=<另一长串>`（见[设置参考](SETTINGS.md)）。
2. 在应用的“高级 → 连接”里输入 `ws://<电脑的地址>:8787/ws?token=<DEVICE_TOKEN>`，然后保存。“**测试连接**”会告诉你能不能连上；连不上时会用大白话说明原因，原始错误信息在“详细信息”里。

这个连接没有加密（`ws://`）：只在你自己的网络里使用，或者在前面架一个 TLS 反向代理并改用 `wss://`。通话走 USB 更稳定。

## 日常使用

- 服务运行时，应用会显示一条不打扰的常驻通知；重启后也会自动启动。
- 想暂时自己用这部手机，把它切换成[普通手机](#普通手机模式)。想让所有手机的 AI 一起停，在网页控制台的设置里关掉“由 AI 接听来电”（电话会被接起来再挂断）。
- 双卡手机会告诉主程序每通电话打到哪一张 SIM。主程序按“各 SIM 卡的主要语言”决定开场语言，短信和回拨也从同一张卡发出。
- AI 代打要先知道手机有哪些 SIM，主程序是从手机上报的来电里学到的。新设置好的手机要先接过一通电话才能代打；在那之前，控制台会提示这部手机还没接过电话。
- 主程序有控制台地址时（设置里的“这个控制台的地址”；没填而控制台对局域网开放时，自动用电脑的局域网地址），应用里会出现“**打开网页控制台**”按钮。

## 普通手机模式

手机有两种模式，除了通话中以外随时可以切换：

| 模式 | 会怎样 |
|---|---|
| **AI 帮我接电话**（默认） | 就是[请用备用手机](#请用备用手机)里说的接管状态。从没切换过的手机，更新后也保持这个模式。 |
| **普通手机** | 来电正常响铃，由你自己接。AI 不接、没有东西被静音，Google 的电话应用也回来了。 |

**在手机上切换：** 打开 Bageo，把最上面的大开关“**AI 帮我接电话**”关掉或打开。确认后等几秒，卡片会显示“普通手机：来电会正常响铃”，或显示 AI 又在接电话了。

**在网页控制台切换：** “系统 → 手机”。每部已连接的手机会显示名称、应用版本、当前模式和一个按钮：“**改成普通手机**”（会先弹出确认框）或“**改回 AI 接听**”。应用版本早于这个功能的手机没有按钮，而是显示“这部手机的 Bageo 应用需要更新，才能从这里切换”。

### 切换时改了什么

切成**普通手机**会依次改这些系统设置：

1. Bageo 不再是来电过滤应用，来电不会再被静音。
2. 关掉勿扰模式。
3. 铃声模式改回正常；铃声、通知、听筒、媒体、闹钟、系统音量恢复成这部手机上次切到 AI 模式前的数值。没保存过、或保存的是 0 的，就用最大值的一半。
4. 麦克风不再被静音，听筒音量也不再被固定在最小。
5. 最后才重新启用 Google 电话（`com.google.android.dialer`），并设为默认电话应用。没有 Google 电话的手机，Bageo 会把这个角色让出来，由 Android 使用自带的电话应用。要确认 Google 电话真的成了默认电话应用、而且没有被停用，这次切换才算完成。

这些设置由模块以 root 身份来改：模块每次开机会启动一个小助手，应用要切换时就由它执行，所以应用不需要 root 权限。Android 拿走某个应用的电话角色时，可能会顺便把它关掉；小助手不受影响，会把设置改完，所以换电话应用放在最后一步。

普通手机模式下，Bageo 的服务会继续运行、保持连接，方便你从网页控制台切回来，但它不会接、不会静音、也不会碰任何一通电话。控制台会把这部手机显示为普通手机，`/health` 的 `normal_mode_serials` 也会列出它。

切回“**AI 帮我接电话**”时，会先保存当前音量，再重做一次模块的接管：Bageo 成为电话应用和来电过滤应用、停用 Google 的电话应用、打开勿扰模式、音量归零。

### 切换没完成时

- 应用和网页控制台会说明是哪一步失败（例如“手机没办法更换默认电话应用”）。再切一次会把每一步重做一遍；切换还没完成时，应用下次启动（例如重启后）也会自己重做。
- 如果应用提示 Bageo 模块没有在运行，请在 Magisk 或 KernelSU 中确认 **Bageo Uplink** 模块已启用，然后重启手机。
- 网页控制台 15 秒内没收到手机回复时，会显示“结果未确认，请稍后刷新。”，稍后刷新就能看到手机报告的模式。

### 模式存在哪里

模式保存在 `/data/adb/pixelcallai/mode`（内容是 `ai` 或 `normal`），在模块文件夹外面，所以重启、更新模块都不会丢。模块每次开机都会读取它；文件不存在就是 AI 模式。上一次切换的结果在同一个文件夹的 `last_apply`，切换还没完成时会有 `pending` 这个文件。普通手机模式要恢复的音量，保存在应用自己的文件夹里。

### 用 adb 切换

不碰手机屏幕、用电脑的 `adb` 切换：

- 立即切换，不用重启（应用会一次把整个切换做完）：

  ```text
  adb shell am start-foreground-service -n com.pixelcallai.streamer/.CallAudioService -a com.pixelcallai.streamer.SET_ENABLED --ez enabled false
  ```

  改成 `--ez enabled true` 就切回“**AI 帮我接电话**”。
- 写入模式文件再重启（应用的服务启动时会把其余设置补上）：

  ```text
  adb shell "su -c 'mkdir -p /data/adb/pixelcallai && echo normal > /data/adb/pixelcallai/mode'"
  adb reboot
  ```

  切回 AI 模式：改写成 `ai`（`echo ai > …`），或用 `adb shell "su -c 'rm -f /data/adb/pixelcallai/mode'"` 删掉这个文件，再重启。

## 还原

要移除 Bageo：

1. 先把手机切成[普通手机](#普通手机模式)。这会恢复 Google 的电话应用、铃声和音量，并关掉勿扰模式，第 3、4 步就不用做了。
2. 在 Magisk 或 KernelSU 里停用或移除 **Bageo Uplink** 模块，然后重启。如果手机启动不到那一步，请使用 root 管理器的安全模式，或者在 recovery 里以 root 身份运行：`touch /data/adb/modules/pixelcallai_uplink/disable`。放模式文件的 `/data/adb/pixelcallai/` 文件夹会保留；以后不打算再装 Bageo 的话，也把它删掉。
3. 如果没先切换就移除了模块：移除模块**不会**恢复 Google 的电话应用，也不会关掉勿扰模式，因为这两样 Android 都会记住。重新启用电话应用：

   ```text
   adb shell su -c "pm enable com.google.android.dialer"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallServiceImpl"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallActivity"
   adb shell su -c "cmd role add-role-holder android.app.role.DIALER com.google.android.dialer"
   adb shell su -c "telecom set-default-dialer com.google.android.dialer"
   ```

4. 到系统设置里关掉勿扰模式，并把音量调回来。
