# 故障排查与常见问题

AI 电话助理一直不接、接起来就挂、预约短信发不出去？在下面的表格里找到你看到的提示或现象，每一行都写了原因和解决办法。最后的常见问题回答 iPhone、root、费用，以及怎样让你的真实号码照常使用。

## 先看这里

1. 打开网页控制台的“**系统**”页，它的检查清单会指出缺了哪一环。
2. 看电脑上 Bageo 的终端窗口：每通电话它都会显示正在做什么（Windows 和 macOS 安装包会在后台搭配 **Bageo Status** 运行、不弹终端窗口；Windows 可跑 `start.cmd -Console`、Linux 可跑 `./start.sh --console` 来查看）。想看更多，在 `.env` 里设置 `RUST_LOG=agent=debug` 后重新启动。日志只记通话里说了多少个字；想看说了什么，再设置 `LOG_CALL_TEXT=1`，查完就关掉。
3. 在手机上打开 Bageo 应用：最上面的卡片会显示有没有连上、现在是哪种模式。

## Bageo 无法启动

| 你看到的 | 原因 | 解决办法 |
|---|---|---|
| `cannot listen on 0.0.0.0:8787` 或 `127.0.0.1:8787 … is another copy running?` | 另一个 Bageo 或别的程序已经占用了这个端口。 | 把它关掉，或者在 `.env` 里设置 `AGENT_PORT=8790`。 |
| `The agent program was not found.`（找不到 Bageo 程序） | 你克隆了源码却没装 Rust，所以没有程序可以运行。 | 安装 [Rust](https://rustup.rs) 后再运行一次启动脚本，或者从 GitHub Releases 安装 Windows 安装包或 macOS 的 `.dmg`。 |
| Windows：“running scripts is disabled on this system”（已禁止运行脚本） | PowerShell 默认不允许运行 `.ps1`。 | 点“Bageo”快捷方式，或在安装文件夹里改用 `start.cmd`，不要直接运行 `start.ps1`；它会用正确的选项启动 PowerShell。 |
| macOS：“cannot be opened because the developer cannot be verified”（无法验证开发者） | App 没有经过 Apple 公证。 | 在 Finder 里对 Bageo 点右键 →“打开”，或到“系统设置 → 隐私与安全性”点“仍要打开”。 |
| 控制台要求输入密码 | 设置了控制台密码或 `CALLS_UI_TOKEN`。 | 输入密码（浏览器会记住），或打开 `http://…:8787/?token=<你的密码>`。 |

## 手机没有出现

“系统 → 手机”会显示连接进行到了哪一步。用 Wi-Fi 而不是 USB 连接的手机，见[手机设置](PHONE.md#wi-fi)。

| 你看到的 | 原因 | 解决办法 |
|---|---|---|
| 找不到 adb | 缺少 Android platform-tools。 | 点 **Bageo Status** 图标并按“下载”、让启动脚本下载（约 7 MB，来自 Google）、自己安装，或者设置 `ADB_BIN`。 |
| 没有列出任何手机 | 数据线或 USB 口只能充电、USB 调试没开，或者 Windows 缺驱动。 | 换一根线、换一个口，打开 USB 调试；Windows 上视需要安装 Google 的 USB 驱动。 |
| `unauthorized` | 手机还没信任这台电脑。 | 解锁手机，在“允许 USB 调试吗？”弹窗里点允许。弹窗没出现：开发者选项 →“撤消 USB 调试授权”，再重新插线。 |
| 这部手机还没有安装 Bageo 应用 | root 模块没装或没有生效。 | 见[手机设置](PHONE.md)。 |
| 已经插上、连接也建立了，却没连上 Bageo | 应用的服务没有运行，或者连不到 Bageo 程序。 | 打开 Bageo 应用，看最上面的卡片、确认每个设置步骤都正常，再点“**高级 → 测试连接**”。Bageo 也会每 90 秒再尝试启动一次服务。 |
| 连上又断开，反复如此 | 电脑上有两个不同版本的 `adb`（Android Studio、手机投屏工具…）在不停地互相重启。 | 把 `ADB_BIN` 设成其中一个，并关掉另一个工具。 |

## 电话没有接，或者声音不对

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 手机一直响，没人接 | 手机处于[普通手机模式](PHONE.md#普通手机模式)（应用卡片写着“普通手机”）、应用的服务没有运行，或者手机没连上 Bageo。12 秒内没连上，应用就完全不接，电话会一直响到运营商按未接处理或转入语音信箱。 | 查看“系统 → 手机”和应用卡片，把手机切回 AI 接听。 |
| 接起来立刻挂断，一句话都没说 | AI 启动不了：没有 Gemini 密钥、密钥错误、模型名称不存在、没有网络，或者“由 AI 接听来电”是关的。通话摘要会写“AI 没接上，没说话”，终端里会显示 Gemini 的错误信息。 | 改正密钥或模型、检查网络、打开“由 AI 接听来电”。 |
| 对方什么都听不到，文字记录里却有 AI 的句子 | 手机没办法把声音播放到通话里（不支持的手机，或者应用不是特权应用）。 | 见 [`android/README.md`](../../android/README.md#troubleshooting)（英文）里的表格。 |
| AI 对对方毫无反应，文字记录里没有对方的句子 | 手机没有把通话音频交给应用。 | 同样是手机支持情况的问题：见[支持哪些手机](PHONE.md#支持哪些手机)。 |
| AI 自问自答，或者抢对方的话 | 手机的录音里有 AI 自己的声音，每通电话开头的回声检测没有发现。 | 关掉“对方可以打断 AI”。 |
| 对方还没说完，AI 就挂断了 | 提示词让它太早说再见。 | 见[编写提示词](PROMPTS.md#自己写或修改)里关于结束的规则。 |
| 通话一直不结束 | 对方一直不挂，始终没说出 Bageo 能识别的道别语。 | 到“普通电话最长”就会结束；经常发生的话把它调短。 |
| 没人说话的电话大约半分钟就挂了 | 有意设计：口袋误拨或只听不说的机器人不该一直占线。 | 不用处理；时间规则见下表。 |
| 境外来电时 AI 开口较晚，或者与预录警示语抢话 | 台湾的运营商会在境外来电前先播放防诈骗警示语。台湾 SIM 接到时，AI 会等线路安静下来（最多 7.5 秒）再说一次开场白。 | 等待时间没有设置可调。手机 App 请保持[最新版](PHONE.md#更新)。 |
| 第二个打来的人说你在忙 | 有意设计：一次只接一通。通话中又打进来的电话会立即被拒接。 | 它会留在通话列表里，你也会收到“通话中插播未接”通知。 |
| 第一句话出来得很慢 | AI 要等接起来才开始连接。 | 开启“响铃时先让 AI 准备好”，并把“响多久再接”保持在 3 秒以上。 |
| 用错了语言回答 | “语言”决定开场白，“各 SIM 卡的主要语言”决定别国 SIM 接到时的开场。 | 检查这两项，并确认提示词里没有把语言写死（例如“一律用中文回答”）。 |

开场语言对了、后来却换了语言？这是有意的：对方明显改说另一种语言时，AI 会跟着换。只有一句很短的“喂？”不会让它换。这默认是开启的；不想让它换语言，可在“设置 → 接听方式”关掉“用对方的语言回答”。

线路安静下来时，Bageo 按固定的时间处理（没有设置可调）：

| 情况 | 会发生什么 |
|---|---|
| 对方从头到尾一句话都没说 | AI 在自己开口 25 秒后（接起后大约 27 秒）收尾挂断。 |
| 通话中途安静下来 | 15 秒后 AI 问“喂？还在吗？”（最多两次），再过 25 秒结束。 |
| 对方说过“等一下” | 45 秒后才问，90 秒后才结束。 |
| 接起来是预录的语音菜单 | AI 不回应；线路安静 4 秒后 Bageo 就挂断。 |

## 推销与诈骗电话

对方推销贷款，或者自称“银行风险管控中心”时，Bageo 可以把他拖住。AI 会变成反应慢、什么都好奇的人，一直追问细节（“陪他聊、拖时间”）。

如果它拖错了人，或者黑名单号码没拦住，看下表：

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 像 `080*` 这样的前缀什么都没拦住 | `*` 前面除了开头的 0，至少要有三位数字（`0800*`），以免一条太短的规则把整个地区或所有来电都拦掉。 | 把前缀写长一点。号码按通话列表里显示的样子写；`+…` 的写法只有在知道你的区号时才能匹配上。 |
| 正常的电话被当成了推销或诈骗 | 判断从关键词开始，而正常来电有时也会说到这些词；之后低成本模型会再看一次。终端会列出是哪些词：`stall engaged … hits=[…]`。 | 在通话页的“推销／诈骗判断”点“不是”：这个号码之后会被当成联系人看待。也可以关掉“陪他聊、拖时间”。 |
| 亲友的电话被拖住了 | 他们没有保存为联系人。 | 在“联系人”里保存他们。 |

联系人的电话在开始陪聊前，Bageo 会再判断一次：说到钱、转账、账单都不会被拖住。但索要验证码、教你操作 ATM 这类话照样会被拖住（来电号码可以伪造）。

## 日程预约与短信

| 你看到的 | 原因 | 解决办法 |
|---|---|---|
| “待处理事项”写着“短信没发出去：手机没连线”（`offline`） | 接那通电话的手机现在没有连接。 | 等它连上后点“**重发短信**”，或者在那里改选另一部已连接的手机。 |
| “手机 App 太旧”（`old_app`） | 发短信需要 1.0 版模块。 | 更新那部手机（[手机设置](PHONE.md#更新)）。 |
| “手机没有信号”（`no_service`）、“飞行模式”（`radio_off`）、“运营商没有接收这条短信”（`generic_failure`） | 运营商没有接收这条短信：没信号、飞行模式、SIM 卡余额不足或停机，或者被运营商拒收。 | 在手机上处理好，再点“**重发短信**”。 |
| “手机没有回应（超时）”（`timeout`）、“手机 App 没有发短信的权限”（`no_permission`）、“手机 App 出错了”（`exception`） | 手机上的应用没能发出。 | 打开 Bageo 应用检查设置步骤，再点“**重发短信**”。 |
| “号码或内容不被接受”（`bad_request`） | 手机不接受这个号码或内容。 | 核对来电者的号码。 |
| 某位来电者没有“发短信”可选 | 固话、免费电话、特殊号码、未显示号码和境外号码都收不到短信。 | “默认回复方式”会改用 AI 回拨，连回拨也不允许时就不通知对方（见[设置](SETTINGS.md#摘要与日历)）。 |
| AI 回拨什么都没说 | 它要等对方接起来出声才说话。70 秒都没人出声就算 `no_answer`。 | “待处理事项”会显示进行到哪一步。 |
| 在网页上决定后，Telegram 卡片上还有按钮 | 按钮会在决定后几秒内去掉。 | 不用处理；点旧卡片只会回复“这个预约已经处理过了”。 |

## AI 代打

AI 代打是你在“AI 代打”页交代、由 AI 替你拨出的电话，例如“订周五晚上 7 点 4 位，可以的话坐户外”。没拨出去或结果没定下来时，页面会告诉你原因：

| 控制台显示 | 原因 | 解决办法 |
|---|---|---|
| “这部手机还没接过电话…”（`sim_unknown`） | 新版手机应用连接时会自动上报 SIM 卡，只有旧版应用或 Android 还没报出 SIM 时才会出现这个提示（免得代打用错国家的卡）。 | 更新手机模块，或先用任何一部电话给它打一通再试。 |
| “没有能打这个国家号码的手机卡。”（`no_sim_for_country`） | 代打只用与号码同一国家的 SIM 拨出。没有 `+` 的号码一律当成本国号码。 | 境外号码写成 `+` 加区号。 |
| “这个号码不能由 AI 拨打”（`not_allowed`） | 紧急号码、7 位以下的短号和增值付费号码一律不拨。用国际冠码（`00…`、`011…`）代替 `+` 写的号码也不拨。 | 改写成 `+` 开头，或者自己打。 |
| “目前没有可用的 AI 手机”（`no_phone`） | 没有手机连接，或者每部都切换成了普通手机。 | 到“系统 → 手机”切回一部。 |
| 一直停在“排队中” | 手机正在通话，或者拨给同一个号码的前一通（代打或预约回拨）还没结束。 | 等着：空闲后会自动拨出。等待超过 10 分钟（`phone_busy`），或排在同号码后面超过 25 分钟（`number_busy`）就放弃。 |
| “手机用了别的 SIM 卡拨出…已立刻挂断”（`wrong_sim`） | Bageo 记住的那张卡被拔掉或换过了。 | 给那部手机打一通，让系统重新识别卡，再点“**再打一次**”。 |
| “需要按键的语音菜单”（`keypad_menu`） | AI 不能按键，最多等 90 秒等人工接听。 | 这种号码请自己打，或者找直拨号码。 |
| “电信语音：…”（`carrier_message`） | 运营商用录音回应（空号、关机）。 | 核对号码。 |
| AI 问的问题没出现在页面上 | 只有你正在看那一条（6 秒内打开着它的实时画面）时，问题才会出现，而且只等 40 秒。没等到的话，AI 会记下对方给的选项、礼貌收尾。 | 结果会是“要你决定”，附上选项，选一个请 AI 回电。 |
| AI 订好了，结果却写“要你决定” | AI 在你没回答的问题上先做了决定。 | 看一下细节，不合适就点“**再打一次**”并写清楚要改什么。 |

## 通知

| 现象 | 原因 | 解决办法 |
|---|---|---|
| “发送测试”显示错误 | 那段文字就是通知服务本身的返回内容，通常是令牌、聊天 ID 或地址填错了。 | 按[通知](NOTIFICATIONS.md)里该服务的步骤检查。 |
| 测试成功，通话后却没收到 | “发送通知”是关的，或者该通知渠道被停用了。 | 两个都打开。 |
| 没有摘要，只有对方开头说的几句 | 没有摘要服务。 | 设置 Gemini 密钥（默认就用它），或者在“摘要与日历”里设置你自己的服务。服务拒绝时，终端里会显示原因。 |
| 通知里的链接打不开 | 你的手机访问不到“设置 → 通知”里的“通知里的地址”，或者 Bageo 只在本机监听（`AGENT_HOST=127.0.0.1`）。 | 见[从其他设备使用控制台](SETTINGS.md#从其他设备使用控制台)。 |
| 日历链接打开的不是我用的那家 | 第一次点“**添加到日历**”时会问要用哪一家，之后就记住。 | 点旁边的“**换一个日历**”。Apple 日历和 `.ics` 链接需要填写“通知里的地址”。 |
| 手机重启后，短信转发读不到短信 | Android 在重启后、第一次输入 PIN 解锁之前，会锁住短信收件箱（Direct Boot）。 | 解锁一次即可，转发工具会自动补上。 |

装了可选的短信 hook 时，解锁前收到的新短信也照样转发。见[短信转发工具](../../tools/sms_forward/README.md#troubleshooting)（英文）。

## 常见问题

**`bageo.local` 打不开？**
依次检查：

- 手机或电脑要和 Bageo 那台电脑连同一个 Wi-Fi（访客网络通常不行）。
- 从别的设备打开时，要先在 Bageo 那台电脑设置好控制台密码，否则只会看到“请先设置密码”。
- Windows 弹出“允许访问”时要选“专用网络”；选错了，到“Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙”把 Bageo 的 `agent.exe` 勾上“专用”。
- 开着“所有流量都走 VPN”的 VPN 时，先关掉 VPN 再试，或见[从其他设备使用控制台](SETTINGS.md#从其他设备使用控制台)。
- 用自己的域名、反向代理或 VPN 的名称打开时看到“用这个地址打不开控制台”：把那个地址填进“通知里的地址”。
- 80 端口被别的程序占用时，改用 `http://bageo.local:8787/`；“系统 → 关于”会显示当前能用的地址。
- 有些旧的 Android 手机打不开 `.local` 地址，请用“系统 → 关于”里的 IP 地址或二维码。

**iPhone 能用吗？不 root 的 Android 呢？**
不能。Android 只允许特权系统应用录下通话并把声音播放到通话里，iOS 则完全不允许。

**不是 Pixel 的 Android 手机能用吗？**
要有人试过才知道，这取决于手机的音频硬件层。见[支持哪些手机](PHONE.md#支持哪些手机)。

**我还能照常使用这部手机吗？**
临时用可以：在应用或网页控制台里切换成[普通手机模式](PHONE.md#普通手机模式)，用完再切回来。

每天用的话，请准备一部备用机，二选一：

- 把 SIM 卡换到备用机上。
- 把主号码的未接来电转移到备用机的号码。主手机会先响，你没接到的才交给 AI。

你自己用 AI 手机拨出的电话，永远不会被静音或被 AI 接手。

**要花多少钱？**
个人与开源社区免费使用（`AGPL-3.0-only`；闭源商用需[取得商业授权](../../COMMERCIAL_LICENSE.md)）。要付的只有这几项：

- Gemini Live 的语音：Google 按用量计费，来电、AI 回拨、AI 代打都算。
- 摘要：只是发给 Gemini 最便宜模型的一次很小的文本请求。
- 手机套餐费用（要能接电话，也能发 AI 替你发的短信、拨 AI 替你打的电话），以及电费。

试听声音和拒接语音都是预录好的，不花钱。

**可以不用 Google、完全离线吗？**
受支持的模式下不行：自然、低延迟的语音靠的就是 Gemini Live。摘要可以改用本地模型（Ollama），见[设置](SETTINGS.md#摘要与日历)。本地语音流水线列在[路线图](ROADMAP.md)里。

**它能打电话或发短信吗？**
可以。**AI 代打**：你在“AI 代打”页写下要办的事，AI 打过去处理、拿不准时问你，最后汇报结果。**AI 回拨**和**短信**则把你对日程预约的答复告诉来电者，短信从那通电话打进来的 SIM 发出。

可选的[短信转发工具](../../tools/sms_forward/README.md)（英文）会把手机收到的短信转发到你的通知与控制台的“**短信**”页，你也可以直接在“短信”页回复。

**它能把通话中的电话转接到我的手机吗？**
可以，请在“设置 → 接听方式”的“转接到你的手机”里设置：可以选“**不接，直接转到你的手机**”（靠运营商遇忙转移），或“**AI 先接，有急事才找你**”（即时通知，另可勾选“**有急事时打给你，三方一起说（试验中）**”由这部手机拨给你并合并三方通话），并自行勾选“**谁打来可以转**”（白名单、其他联系人、不在联系人里的号码）。

**多部手机、多个号码？**
可以：把好几部手机插到同一台电脑上，它们共用同一份设置。

**录音在哪里？怎么删除？**
在 `data/calls/<date>/`。超过“设置 → 高级”的“记录保留几天”（默认 15 天）会自动删除；把文件夹删掉就一次清空。

**对方会知道这是 AI 吗？**
用“AI 助理”方式时，第一句话就会说。用“本人”方式时，AI 以你的身份说话，不会说自己是 AI。后者在你所在的地方是否允许，需要你自己查清楚，见[隐私、安全与法律](PRIVACY_AND_LEGAL.md)。

## 反馈问题

提一个 issue，写上：你的系统（Windows、macOS 或 Linux）、手机型号和 Android 版本、Bageo 版本（“系统”页最下方）、你做了什么、你预期会怎样，以及 Bageo 终端输出里相关的几行。先把电话号码和密钥去掉，绝对不要贴出 `settings.json`。
