# 故障排查与常见问题

先看网页控制台的“**系统**”页：它的检查清单会指出缺了哪一环。主程序的终端窗口会显示它正在做什么；在 `.env` 里设置 `RUST_LOG=agent=debug` 可以看到更多信息。

## 主程序无法启动

| 你看到的 | 怎么处理 |
|---|---|
| `cannot listen on 127.0.0.1:8787 … is another copy running?` | 有另一个主程序（或别的程序）占用了这个端口。把它关掉，或者在 `.env` 里设置 `AGENT_PORT=8790`。 |
| “The agent program was not found”（找不到主程序） | 你克隆了源码，但没有安装 Rust。请安装 [Rust](https://rustup.rs) 后再运行一次启动脚本，或者改用发行版的安装包。 |
| Windows：“running scripts is disabled”（已禁止运行脚本） | 请用 `start.cmd`（它会用正确的选项启动 PowerShell），不要直接运行 `start.ps1`。 |
| macOS：“cannot be opened because the developer cannot be verified”（无法打开，因为无法验证开发者） | 右键点击 →“打开”，或到“系统设置 → 隐私与安全性”里允许它，或在该文件夹里运行 `xattr -dr com.apple.quarantine .`。 |
| 网页要求输入访问令牌 | 设置了 `CALLS_UI_TOKEN`：输入它（浏览器会记住），或打开 `http://…:8787/?token=<your token>`。 |

## 手机没有出现

“系统 → 手机”会告诉你它进行到了哪一步。

| 显示的内容 | 怎么处理 |
|---|---|
| 找不到 adb | 让启动脚本下载 platform-tools、自己安装，或者设置 `ADB_BIN`。 |
| USB 上没有找到手机 | 数据线或 USB 口的问题（换一个试试；有些线只能充电）。USB 调试没开。在 Windows 上，手机可能需要 Google 的 USB 驱动。 |
| `unauthorized` | 解锁手机，在“允许 USB 调试吗？”弹窗里点允许。如果弹窗没有出现：开发者选项 →“撤消 USB 调试授权”，再重新插线。 |
| 这部手机还没有安装 Bageo 应用 | 模块没有安装或没有生效——见[手机设置](PHONE.md)。 |
| 已经插上 USB、连接也建立了，但没有连上主程序 | 打开 Bageo 应用：最上面的卡片写的是什么？设置步骤每一步都正常吗？点“**高级 → 测试连接**”。主程序每 90 秒会再尝试启动一次服务。 |
| 连上又断开，反复如此 | 电脑上有两个不同版本的 `adb`（Android Studio、手机投屏工具…）在不停地互相重启对方。把 `ADB_BIN` 设成其中一个，并关掉另一个工具。 |

## 电话没有接，或者声音不对

| 现象 | 可能的原因 |
|---|---|
| 手机一直响个不停 | 手机处于[普通手机模式](PHONE.md#普通手机模式)（应用的卡片写着“普通手机”）、应用的服务没有运行，或者手机没连上主程序：12 秒内没连上，应用完全不会接，电话会一直响到运营商按未接来电处理或转入语音信箱。请查看“系统 → 手机”和应用的卡片。 |
| 接起来就立刻挂断，什么都没说 | AI 启动不了：没有 Gemini 密钥、密钥错误、模型名称不存在、没有网络，或者控制台里的“由 AI 接听来电”是关的。通话记录的摘要会写“AI 没接上，没说话”；终端里会显示 Gemini 的错误信息。 |
| 对方什么都听不到，但 AI 看起来在回答（文字记录里有 AI 的句子） | 手机没办法把声音播放到通话里（不支持的手机，或者应用不是特权应用）。见 [`android/README.md`](../../android/README.md#troubleshooting)（英文）里的表格。 |
| AI 对对方完全没有反应（文字记录里没有对方的句子） | 手机没有把通话音频交给应用——同样是手机支持情况的问题。 |
| AI 自己回答自己／抢对方的话 | 手机的录音里包含 AI 自己的声音，而回声检测没有发现。请关掉“对方可以打断 AI”。 |
| AI 挂断得太早 | 它的提示词让它在对方还没说完之前就说了再见。见[编写提示词](PROMPTS.md#自己写或修改)里关于结束的规则。 |
| 通话一直不结束 | 对方始终没说出主程序能识别的道别语，又一直不挂；要到“普通电话最长”才会结束。经常发生的话，把它调短。 |
| 没人说话的电话大约半分钟就挂了 | 这是有意设计的。对方从头到尾一句话都没说时，AI 在自己开口 25 秒后（接起后大约 27 秒）收尾挂断，口袋误拨或只听不说的机器人不会一直占线。通话中途线路安静下来时，AI 会在 15 秒后问“还在吗？”（最多两次），再过 25 秒结束；对方说过“等一下”时，45 秒后才问、90 秒后才结束。预录的语音菜单 AI 不会回答：线路安静 4 秒后主程序就挂断。 |
| 境外来电时 AI 开口较晚，或与预录警示语抢话 | 台湾的运营商会在境外来电播放防诈骗警示语。台湾 SIM 接到时，AI 会等线路安静下来（最多 7.5 秒）再说一次开场白。这一项没有设置可调。手机 App 早于 1.0（0.2.4 及更早）时，主程序不知道是哪张卡接的，改看号码的区号（[`COUNTRY_CODE`](SETTINGS.md#国际电话区号)）。 |
| 第二个打来的人说你在忙 | 这是有意设计的：一次只接一通。通话中又打进来的电话会立即被拒接，留在通话列表里，并发出“📵 通话中插播未接”通知。 |
| 像 `080*` 这样的前缀什么都没拦住 | `*` 前面至少要有四位数字（`0800*`），以免一条太短的规则把整个地区或所有手机号码都拦掉。号码请按通话列表里显示的样子写；`+…` 的写法只有在知道你的区号时才能匹配上。 |
| 第一句话出来得很慢 | 开启“响铃时先让 AI 准备好”，并把“响多久再接”保持在 3 秒以上。 |
| 用错了语言回答 | “语言”决定开场用的语言（另一张 SIM 的开场看“各 SIM 的语言”）。之后对方明显说另一种语言时 AI 会跟着换；只有一句很短的“喂？”不会让它换。 |
| 正常的电话被当成了推销／诈骗 | 关掉“陪他聊、拖时间”，或者告诉我们是哪些词触发的（主程序的终端输出里会列出来：`stall engaged … hits=[…]`）。 |
| 亲友的电话被当成了推销／诈骗 | 把他们保存为联系人：主程序在开始陪聊前会再判断一次，联系人谈到钱、转账、账单都不会被当成推销或诈骗。 |

## 日程预约与短信

| 现象 | 怎么处理 |
|---|---|
| “待处理事项”写着“短信没发出：手机没连线”（`offline`） | 接那通电话的手机现在没有连接。等它连上后点“**重发短信**”，或在那里改选另一部已连接的手机。 |
| “手机 App 太旧，不支持发短信”（`old_app`） | 在那部手机上安装 1.0 版模块（[手机设置](PHONE.md#更新)）。 |
| “失败代码 generic_failure”／`no_service`／`radio_off` | 运营商没有接收这条短信：没信号、飞行模式，或预付费卡没有余额（很常见的原因：卡里余额用完了）。在手机上处理好之后点“**重发短信**”。 |
| 某位来电者没有“发短信”可选 | 固话、免费电话、特殊号码、未显示号码和境外号码收不到短信；“默认回复方式”会改用 AI 回拨，连回拨也不允许时就不通知（见[设置](SETTINGS.md#摘要与日历)）。 |
| AI 回拨什么都没说 | 它要等对方接起来出声才说话；70 秒都没人出声就算 `no_answer`。“待处理事项”会显示进行到哪一步。 |
| 在网页上决定后，Telegram 卡片还有按钮 | 按钮会在决定后几秒内去掉；在旧卡片上点只会回复“这个预约已经处理过了”。 |

## AI 代打

| 控制台显示 | 原因与处理方式 |
|---|---|
| “这部手机还没接过电话”（`sim_unknown`） | 主程序是从手机上报的来电里学到每部手机有哪些 SIM——哪个订阅 id 是哪个国家的卡——这样代打才不会用别国的卡打本国号码（变成昂贵的国际长途，或根本打不通）。装好后还没接过任何电话的手机暂时不能用：用任何一部电话给它打一通，再试一次。 |
| “没有能打这个国家号码的手机卡”（`no_sim_for_country`） | 代打只用与号码同一个国家的 SIM 拨出。境外号码请写 `+` 和区号；没有 `+` 就当成本国号码。 |
| “这个号码不能由 AI 拨打”（`not_allowed`） | 紧急号码、7 位以下的短号和增值付费号码一律不拨；用国际冠码（`00…`、`011…`）代替 `+` 写的号码也不拨。 |
| “目前没有可用的 AI 手机”（`no_phone`） | 没有手机连接，或每部都切换成了普通手机。到“系统 → 手机”切回一部。 |
| 一直停在“排队中” | 手机正在通话，或拨给同一个号码的前一通（代打或预约回拨）还没结束。空闲后会自动拨出；等待超过 10 分钟（`phone_busy`），或排在同号码后面超过 25 分钟（`number_busy`）就放弃。 |
| “手机用了别的 SIM 卡拨出…已立刻挂断”（`wrong_sim`） | 主程序记住的那张卡不见了或换过了。给那部手机打一通，让系统重新识别卡，再点“**再打一次**”。 |
| “需要按键的语音菜单”（`keypad_menu`） | AI 不能按键。它最多等 90 秒等人工接听；这种号码请自己打，或找直拨号码。 |
| “电信语音：…”（`carrier_message`） | 运营商用录音回应（空号、关机）。请核对号码。 |
| AI 问的问题没出现在页面上 | 只有你正在看那一条（6 秒内打开着它的实时画面）时问题才会出现，而且只等 40 秒。否则 AI 会记下对方的选项、礼貌收尾；结果是“要你决定”，附上选项让你选一个请 AI 回电。 |
| AI 订好了，结果却写“要你决定” | AI 在你没回答的问题上先做了决定。看一下细节，不合适就点“**再打一次**”并写清楚要改什么。 |

## 通知

| 现象 | 怎么处理 |
|---|---|
| “发送测试”显示错误 | 那段文字就是服务本身的返回内容——通常是 token、chat ID 或 URL 填错了。各服务的步骤：[通知](NOTIFICATIONS.md)。 |
| 测试成功，但通话后没有消息 | “发送通知”是关的，或者该渠道被停用了。 |
| 没有摘要，只有对方开头说的几句话 | 没有摘要服务：请设置 Gemini 密钥（默认就是用它），或者在“摘要与日历”里设置你自己的服务。如果服务拒绝了，终端里会显示原因。 |
| 通知里的链接打不开 | “这个控制台的地址”必须是你手机能访问到的地址，而且主程序要在网络上监听——见[设置参考](SETTINGS.md#从其他设备使用控制台)。 |
| 日历链接打开的不是我用的日历 | 在控制台第一次点“添加到日历”时会问要用哪一家；按钮旁的“更换”可以修改。Apple 日历／`.ics` 的链接需要填写“这个控制台的地址”。 |
| 手机重启后，短信转发读不到短信 | Android 在重启后、第一次输入 PIN 解锁之前，会锁住短信收件箱（Direct Boot）。解锁一次即可，转发工具会自动补上。装了可选的短信 hook 时，首次解锁前收到的新短信也照样转发。见[短信转发工具](../../tools/sms_forward/README.md#troubleshooting)（英文）。 |

## 常见问题

**iPhone 能用吗？不 root 能用吗？**
不能。Android 只允许特权系统应用录下通话并把声音播放到通话里，iOS 则完全不允许。

**我的（非 Pixel）Android 手机能用吗？**
要有人试过才知道；这取决于手机的音频硬件层。见[手机设置](PHONE.md#支持哪些手机)。

**我还能照常使用这部手机吗？**
临时用可以：在应用或网页控制台里把它切换成[普通手机](PHONE.md#普通手机模式)，用完再切回来。每天用的话，请用备用手机，或者把 SIM 卡换过去（也可以把主号码设置呼叫转移到备用手机的号码——这样你的主手机会先响，没接的电话才交给 AI）。你自己用这部手机拨出的电话，永远不会被静音或被 AI 接手。

**要花多少钱？**
软件免费。Gemini Live 音频由 Google 按用量计费（来电、AI 回拨、AI 代打都一样）；摘要只是发给 Gemini 最便宜模型的一次很小的文本请求。试听声音和拒接语音都是预先录好的，不花钱。还需要一个能接电话（也能发 AI 替你发的短信、打 AI 替你拨的电话）的手机套餐，以及电费。

**可以不用 Google／完全离线运行吗？**
在受支持的模式下不行：自然、低延迟的语音靠的就是 Gemini Live。摘要可以改用本地模型（Ollama）——见[设置参考](SETTINGS.md#摘要与日历)。本地语音流水线列在[路线图](ROADMAP.md)里。

**它能拨出电话或发短信吗？**
可以。拨电话有两种：**AI 代打**——你在“代打”页写下要办的事，AI 打过去处理、拿不准时问你、最后汇报结果；以及告诉来电者日程预约结果的 **AI 回拨**。**发短信**是把你对日程预约的回复发给来电者，从那通电话打进来的 SIM 发出。可选的[短信转发工具](../../tools/sms_forward/README.md)（英文）则会把手机收到的短信转发到你的通知。

**它能把正在进行的通话转接到我的手机吗？**
目前还不行。不支持把通话中的电话实时转接给真人；AI 会记下留言或把事情办完，再由你回电。

**多部手机／多个号码？**
可以：把好几部手机插到同一台电脑上。它们共用同一份设置。

**我的录音在哪里？怎么删除？**
在 `data/calls/<date>/`。超过 `CALLS_RETENTION_DAYS`（默认 7）天就会被删除；把文件夹删掉就全部清除了。

**对方会被告知这是 AI 吗？**
用“AI 助理”方式时，第一句话就会说。用“本人”方式时，只有对方认真问起才会说。后者在你所在的地方是否允许，需要你自己查清楚——见[隐私、安全与法律](PRIVACY_AND_LEGAL.md)。

## 反馈问题

提一个 issue，内容包括：你的系统（Windows / macOS / Linux）、手机型号和 Android 版本、主程序版本（在“系统”页最下方）、你做了什么、你预期会怎样，以及主程序终端输出里相关的几行。请先把电话号码和密钥去掉。绝对不要贴出 `settings.json`。
