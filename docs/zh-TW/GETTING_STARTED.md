# 開始使用：讓 AI 電話助理接聽你的真實門號

這份指南帶你從下載開始，一路做到 AI 用你自己的門號接起第一通電話，再讓 AI 第一次替你打電話。Bageo 是自架的：一支 root 過的 Android 手機插著你的 SIM 卡，電腦上的一個程式把每通電話即時串到 Gemini Live，所有錄音和逐字稿都留在你硬碟上的資料夾。請預留大約一小時，大部分時間花在準備手機。

## 1. 需要準備什麼

| | |
|---|---|
| **一支備用 Android 手機** | 已用 Magisk 或 KernelSU root，Android 10 以上，插著能接電話的 SIM 卡。在 Google Pixel 7、7a、8、9 實測過（見[支援哪些手機](PHONE.md#支援哪些手機)）。這裡不教 root：請照你那個型號的教學做，並記得解鎖 bootloader 會清空手機。 |
| **一台電腦** | Windows 10/11、macOS（Apple Silicon 或 Intel）或 Linux，要接電話的時段都得開著，再加一條接手機的 USB 線。也可以用 Docker，手機改走 Wi-Fi。 |
| **一把 Gemini API 金鑰** | 到 <https://aistudio.google.com/apikey> 建立並複製。Bageo 只需要這一把：即時通話、摘要、防詐複審、聯絡人匯入都用它。Google 依用量計費；想設上限，可以在 Google 帳戶裡設定預算。 |

## 2. 安裝並啟動主程式

「主程式」（agent）就是電腦上的那個程式：它跟手機和 Gemini 溝通、保存通話紀錄，也提供網頁控制台。只有這一個程式，不需要資料庫，也不用另外裝其他服務。

### 下載發行版（最簡單）

1. 到 [Releases](https://github.com/h4lo-void/bageo-call/releases) 頁面下載你系統的套件，解壓縮到任何位置（例如 `Documents/bageo-call`）：

   | 系統 | 套件 |
   |---|---|
   | Windows | `bageo-call-1.0.0-windows-x64.zip` |
   | macOS（Apple Silicon） | `bageo-call-1.0.0-macos-arm64.tar.gz` |
   | macOS（Intel） | `bageo-call-1.0.0-macos-x64.tar.gz` |
   | Linux | `bageo-call-1.0.0-linux-x64.tar.gz` |

   每個套件都包含主程式、內建音檔、啟動腳本和文件。
2. 啟動：
   - **Windows：** 按兩下 `start.cmd`。如果 SmartScreen 警告發行者不明，請選「其他資訊 → 仍要執行」。
   - **macOS：** 按兩下 `start.command`。程式沒有經過公證（notarize），第一次 macOS 可能會擋：在 `start.command` 上按右鍵 →「打開」；如果被擋的是主程式本身，到「系統設定 → 隱私權與安全性」允許它。也可以在該資料夾的終端機執行一次 `xattr -dr com.apple.quarantine .`。
   - **Linux：** 在終端機執行 `./start.sh`。
3. 腳本會找 `adb`（Google 的 Android platform-tools，USB 連線要用）。沒裝的話，腳本會問要不要從 Google 下載到程式旁邊的 `platform-tools` 資料夾。
4. 瀏覽器會打開網頁控制台 <http://localhost:8787/>。終端機視窗請保持開著：關掉它，主程式就停了。
5. 主程式第一次啟動成功時，腳本會在桌面放一個「**Bageo 控制台**」捷徑（macOS 是 `.webloc` 檔；Linux 是應用程式選單裡的項目，也會複製到桌面資料夾）。捷徑還在就不會重做。不想要的話，啟動時加 `-NoShortcut`（Windows）或 `--no-shortcut`，或在 `.env` 設 `BAGEO_NO_SHORTCUT=1`。

### 從原始碼

```text
git clone https://github.com/h4lo-void/bageo-call.git
cd bageo-call
./start.sh            # Windows: .\start.cmd
```

裝好 [Rust](https://rustup.rs) 後，啟動腳本第一次會先建置主程式（要幾分鐘）再啟動。拉了新程式碼之後，加 `--build`（PowerShell：`-Build`）重新建置。

### 用 Docker

```text
cp .env.example .env        # 設定 CALLS_UI_TOKEN 和 DEVICE_TOKEN
docker compose up -d --build
```

在容器裡，主程式對區網開放，所以兩個權杖都必須設定。控制台網址是 `http://<主機>:8787/?token=<CALLS_UI_TOKEN>`，手機透過 Wi-Fi 連到 `ws://<主機>:8787/ws?token=<DEVICE_TOKEN>`（見[手機設定 → Wi-Fi](PHONE.md#wi-fi)）。容器裡的主程式不會回應 `bageo.local`，也沒辦法自己算出通知連結要用的控制台網址，所以請在 `.env` 設 `PUBLIC_URL`（例如 `http://192.168.1.20:8787`）。時區設定寫在 `docker-compose.yml` 的註解裡。

### 資料存在哪裡

全部都在你啟動程式的那個資料夾（Docker 是 `/data/calls`）：

| 路徑 | 內容 |
|---|---|
| `data/calls/` | 通話紀錄、錄音、逐字稿、聯絡人、待處理事項、AI 代打紀錄 |
| `data/calls/config/settings.json` | 你在網頁控制台設定的所有內容，**包括你的 API 金鑰** |
| `.env` | 選用的啟動選項（連接埠、權杖）；見[設定參考](SETTINGS.md) |

`data/` 要備份或刪除都隨你。不會存到其他任何地方。

## 3. 填好基本設定

在網頁控制台打開「設定」。

1. **語言**：AI 講話用的語言。「通知和摘要的語言」可以設成別的，例如 AI 用英文接電話，你看的通知維持繁體中文。（控制台本身的顯示語言，是頁首的切換鈕。）
2. **你的名字**：來電的人怎麼稱呼你（「Alex」、「陳小姐」、「王先生」）。
3. **其他人怎麼叫你**：一行一個，最多 10 個。英文名、綽號、簡稱（「Lex」）。AI 聽到這些名字，就知道對方在找你。
4. **接聽身分**
   - 「AI 助理」：「您好，這裡是 Alex 的 AI 助理，他現在不方便接電話，請問有什麼需要我轉達的嗎？」來電的人一聽就懂，在法律上也比較安全。
   - 「本人」：AI 照你的習慣說「喂？」，以你的身分講話。它不會替你答應任何事，有人認真問時也會承認自己是 AI，但來電的人通常會以為就是你。請先讀[隱私、安全與法律](PRIVACY_AND_LEGAL.md)。
5. **Gemini API 金鑰**：貼上並儲存。摘要預設也用這把金鑰（Gemini 最便宜的模型）；只有在「摘要服務」選了「其他服務」（例如 DeepSeek、OpenRouter 或本機的 Ollama）時才需要另一把。
6. **聲音**：按清單旁邊的 ▶，聽每個聲音用你的語言講幾句。這些範例隨程式內建，試聽不花錢。

儲存。「系統」頁的檢查清單會列出還缺什麼。

## 4. 準備手機

下面是精簡版；詳細說明與還原方式見[手機設定](PHONE.md)。

1. 把發行版附的 `pixelcallai_uplink-<version>.zip` 複製到手機，在 Magisk 或 KernelSU App 裡安裝成模組。重新開機。
2. 打開 **Bageo** App，把「**設定步驟**」一項一項做完：權限、預設電話 App、來電過濾、勿擾模式權限、電池最佳化例外。App 本身不需要 root 權限，這些事由模組代勞。
3. 開啟 **USB 偵錯**：「設定 → 關於手機」，連點「版本號碼」七次，再到「系統 → 開發人員選項 → USB 偵錯」。
4. 把手機接上電腦。在手機上的「**允許 USB 偵錯嗎？**」按允許，並勾選「一律允許透過這台電腦進行」。

大約 15 秒內，主程式會自己設好 USB 連線並啟動 App 的通話服務。網頁控制台的「系統 → 手機」會列出這支手機，先顯示已插上，接著顯示已連線。

> 從現在起，這支手機就是一台接電話專用機：它不會響出聲，原本的電話 App 被隱藏，通話時麥克風和喇叭都靜音，房間裡的聲音不會被聽到。這是刻意的設計。想暫時當一般手機用，在「系統 → 手機」或 App 裡切成[一般手機模式](PHONE.md#一般手機模式)，隨時都能切回來。

## 5. 打第一通測試電話

用另一支手機撥這支手機的號碼。

1. 你這邊會聽到響一聲，大約三秒（「響多久再接」；0 = 馬上接）。這一聲的時間裡，AI 已經連上並準備好第一句話。
2. AI 接起來。跟它聊、打斷它、換一種語言問它，然後說再見。
3. 掛斷幾秒後，這通電話會出現在「通話」裡，附上錄音（整通、只有對方、只有 AI）、逐字稿和四行摘要：對方、事情、AI 回覆、要處理。用其他語言講的句子保留原文，下面附翻譯。

**試試看：** 再打一次，假裝推銷保險。「推銷與詐騙電話 → 陪他聊、拖時間」開著時（預設就是開），AI 會裝作有興趣、一項一項問細節，把你留在線上，但不會給任何資料，也不會答應任何事。

如果沒人接，請看[疑難排解](TROUBLESHOOTING.md)；「系統」頁通常會告訴你缺了哪一塊。

## 6. 設定通知

到「設定 → 通知 → 新增管道」，選一個服務，填好欄位（每個欄位都有提示告訴你去哪裡找），按「**傳送測試**」。想加幾個都可以，每則訊息會送到全部管道。總共支援 32 種服務，從 Telegram（預約卡片有「同意／不同意」按鈕）到自訂 webhook。各服務的設定方式：[通知](NOTIFICATIONS.md)。

想讓通知裡的連結能直接打開那通電話，請把控制台對區網開放（見[從其他裝置使用控制台](SETTINGS.md#從其他裝置使用控制台)）。之後連結會指向 `http://bageo.local:8787/`（主程式能回應這個名稱時），否則指向電腦的區網位址；「系統 → 關於」會顯示目前用哪一個，並附 QR code。只有在你用別的方式連到這台電腦時（VPN 名稱、反向代理、Docker），才需要填「**這個控制台的網址**」。

想在自己手機上開控制台：掃那個 QR code，再把頁面加到主畫面（iPhone：「分享 → 加入主畫面」；Android：Chrome 選單 ⋮ →「加到主畫面」）。之後點 Bageo 圖示就能打開。

## 7. 聯絡人、行程預約與 AI 代打

接電話用不到這些功能，每一項都只要幾分鐘。

### 聯絡人

到「聯絡人 → 匯入」，丟一個檔案進去：

- 從手機匯出的 vCard（`.vcf`），或 Google 聯絡人、Outlook 的 CSV；
- 存成 CSV 或 TSV 的試算表，或 Excel `.xlsx`、Word `.docx` 裡的表格；
- 每行一個名字加號碼的純文字；
- PDF、名片照片或通訊錄截圖（由 Gemini 辨識）。

存檔前每一筆都會先給你看，重複的可以選擇合併或略過。聯絡人的備註（「我妹」「房東」）會在那個人打來時放進 AI 的提示詞。在某通電話的詳細資料裡按「**加入聯絡人**」，也能把來電者存起來。

### 行程預約

到「設定 → 摘要與行事曆 → 行程預約 → 先問我」開啟。來電的人想約時間時，AI 會說確認一下再回覆；通話結束後，這筆預約會出現在「通話」頁最上面的「**待處理事項**」。選好怎麼告訴對方（**傳簡訊**、**AI 回電**或**不通知對方**），再按「**同意**」或「**不同意**」。要傳簡訊，還得打開「傳簡訊告訴對方」。第一次在同意的預約上按「**加入行事曆**」時，選你用的行事曆（Google、Outlook.com、Microsoft 365、Apple、Yahoo 或 `.ics`），之後按下去就直接加入。

### 第一次 AI 代打

手機要先接過至少一通電話，主程式才知道它插了哪些 SIM 卡。接著打開「**AI 代打**」：

1. **打給誰**：輸入聯絡人名字或號碼。沒有 `+` 的號碼視為你所在國家的號碼；國外號碼請用 `+` 開頭。AI 只會用跟號碼同一國的 SIM 卡撥打。
2. **要處理的事**：寫清楚要辦什麼、哪些條件可以接受，例如：「訂明天晚上 7 點 4 位，姓王，非吸菸區；7 點半到 8 點也可以。」
3. **用什麼身分打**：你的助理（預設）或你本人。
4. 按「**開始打**」，並保持頁面開著。即時字幕會顯示雙方在說什麼。如果餐廳只剩 8 點半，AI 會跳出一張 40 秒倒數的提問卡問你；「**交代 AI**」也能隨時給它指示。

結果會出現在「交辦紀錄」裡，並只發一則通知。結果寫「要你決定」時，從選項挑一個或自己寫回覆，再讓 AI 打一次。

## 8. 讓它一直開著

主程式在跑，才接得到電話。

- **Windows：** 把 `start.cmd` 的捷徑放進「啟動」資料夾（`Win+R` → `shell:startup`），或在「工作排程器」建立一個「登入時」執行 `start.cmd -NoBrowser` 的工作。插電時關閉睡眠。
- **macOS：** 「系統設定 → 一般 → 登入項目」→ 加入 `start.command`，並防止睡眠（「電池／能源 → 防止自動進入睡眠」）。
- **Linux：** 建立一個 systemd 使用者服務：

  ```ini
  # ~/.config/systemd/user/bageo-call.service
  [Unit]
  Description=Bageo agent
  After=network-online.target

  [Service]
  WorkingDirectory=%h/bageo-call
  ExecStart=%h/bageo-call/start.sh --no-browser --yes
  Restart=on-failure

  [Install]
  WantedBy=default.target
  ```

  再執行 `systemctl --user enable --now bageo-call`，以及 `loginctl enable-linger $USER`，讓它在沒登入時也會跑。
- **Docker：** `docker-compose.yml` 裡的 `restart: unless-stopped` 已經會在重開機後把它帶起來。

手機請一直接著充電器。手機或電腦重新開機後，兩邊都會自己重新連上。
