從零開始，到 AI 接起第一通電話，再到 AI 第一次替你打電話。請預留大約一小時，大部分時間花在準備手機。

## 1. 需要準備什麼

- 一支**備用的 Android 手機**，裝有能接電話的 SIM 卡，已用 Magisk 或 KernelSU **root**，Android 10 以上。在 Google Pixel 7、7a、8、9 上實測過。這裡不說明怎麼 root；請照著你那個型號的教學做，並記得解鎖 bootloader 會把手機清空。
- 一台**電腦**（Windows 10/11、Apple Silicon 或 Intel 的 macOS、Linux），需要接電話的時段要一直開著；還要一條接手機的 USB 線。也可以用 Docker，手機改走 Wi-Fi。
- 一把 **Gemini API 金鑰**：到 <https://aistudio.google.com/apikey> 登入，建立金鑰並複製下來。Bageo 只需要這一把：即時通話、摘要、防詐複審、聯絡人匯入都用它。Google 依用量計費；想設上限的話，可以在 Google 帳戶裡設定預算。

## 2. 安裝並啟動主程式

「主程式」（agent）就是電腦上的那個程式：它跟手機和 Gemini 溝通、保存通話紀錄，也提供網頁控制台。它是單一程式，不需要資料庫，也不用另外安裝其他服務。

### 簡單的方法：下載發行版

1. 從 [Releases](https://github.com/h4lo-void/bageo-call/releases) 頁面下載適合你系統的套件，解壓縮到任何位置（例如 `Documents/bageo-call`）：`bageo-call-1.0.0-windows-x64.zip`、`-macos-arm64.tar.gz`（Apple Silicon）、`-macos-x64.tar.gz`（Intel）或 `-linux-x64.tar.gz`。每個套件都包含主程式、內建音檔、啟動腳本和文件。
2. 啟動：
   - **Windows：** 按兩下 `start.cmd`。如果 Windows SmartScreen 警告發行者不明，請選「其他資訊 → 仍要執行」。
   - **macOS：** 按兩下 `start.command`。第一次執行時，macOS 可能會因為程式沒有經過公證（notarize）而拒絕開啟：請在 `start.command` 上按右鍵 →「打開」；如果被擋下的是主程式本身，請到「系統設定 → 隱私權與安全性」允許它。也可以在終端機裡，於該資料夾執行一次 `xattr -dr com.apple.quarantine .`。
   - **Linux：** 在終端機執行 `./start.sh`。
3. 腳本會尋找 `adb`（Google 的 Android platform-tools，USB 連線需要它）。如果沒有安裝，腳本會詢問要不要從 Google 下載，放到程式旁邊的 `platform-tools` 資料夾。
4. 瀏覽器會打開網頁控制台 <http://localhost:8787/>。終端機視窗請保持開啟：把它關掉，主程式就停了。
5. 主程式第一次啟動成功時，腳本會在桌面放一個「**Bageo 控制台**」捷徑（macOS 是 `.webloc` 檔；Linux 是應用程式選單裡的項目，也會複製到桌面資料夾）。下次用它打開控制台就好。捷徑還在就不會重做；不想要的話，啟動時加 `-NoShortcut`（Windows）／`--no-shortcut`，或在 `.env` 設 `BAGEO_NO_SHORTCUT=1`。改名前留下的「Myna 控制台」捷徑也算數，舊的 `MYNA_NO_SHORTCUT=1` 照樣有效。

### 從原始碼

```text
git clone https://github.com/h4lo-void/bageo-call.git
cd bageo-call
./start.sh            # Windows: .\start.cmd
```

裝好 [Rust](https://rustup.rs) 之後，啟動腳本第一次會先建置主程式（要幾分鐘），然後啟動。拉了新程式碼之後，加 `--build`（PowerShell：`-Build`）重新建置。

### 用 Docker

```text
cp .env.example .env        # 設定 CALLS_UI_TOKEN 和 DEVICE_TOKEN
docker compose up -d --build
```

在容器裡，主程式是對區網開放的，所以兩個權杖都必須設定。控制台網址是 `http://<主機>:8787/?token=<CALLS_UI_TOKEN>`，手機透過 Wi-Fi 連到 `ws://<主機>:8787/ws?token=<DEVICE_TOKEN>`（見[手機設定 → Wi-Fi](PHONE.md#wi-fi)）。主程式在容器裡不會回應 `bageo.local`，也沒辦法自己填好通知連結用的控制台網址：請在 `.env` 設 `PUBLIC_URL`（例如 `http://192.168.1.20:8787`）。時區和從 Myna 舊名升級的做法，寫在 `docker-compose.yml` 的註解裡。

### 東西存在哪裡

全部都在你啟動程式的那個資料夾裡（Docker 是 `/data/calls`）：

| | |
|---|---|
| `data/calls/` | 通話紀錄、錄音、逐字稿、聯絡人、待處理事項、AI 代打紀錄 |
| `data/calls/config/settings.json` | 你在網頁控制台設定的內容，**包括你的 API 金鑰** |
| `.env` | 選用的啟動選項（連接埠、權杖）；見[設定參考](SETTINGS.md) |

`data/` 要備份或刪除都隨你。不會存到任何其他地方。

## 3. 填好基本設定

在網頁控制台打開「設定」。

1. **語言**：AI 講話用的語言。「通知語言」可以不一樣，例如 AI 用英文接電話，你看的通知維持繁體中文。（控制台本身的顯示語言，是頁首那個切換鈕。）
2. **你的名字**：來電的人怎麼稱呼你（「Alex」、「陳小姐」、「王先生」）。
3. **其他人怎麼叫你**：一行一個，最多十個。英文名、綽號、簡稱（「Lex」）。AI 聽到這些名字，就知道對方在找你。
4. **接聽身分**
   - 「AI 助理」：「您好，這裡是 Alex 的 AI 助理，他現在不方便接電話，請問有什麼需要我轉達的嗎？」對來電者很清楚，在法律上也是比較安全的選擇。
   - 「本人」：AI 照你的方式說「喂？」，以你的身分講話。它不會替你做任何承諾，有人認真問起時也會承認自己是 AI，但來電的人通常會以為就是你。請先讀[隱私、安全與法律](PRIVACY_AND_LEGAL.md)。
5. **Gemini API 金鑰**：貼上並儲存。摘要預設也用同一把金鑰（Gemini 最便宜的模型）；只有在「摘要服務」選了「其他服務」（例如 DeepSeek、OpenRouter 或本機的 Ollama）時才需要另一把金鑰。
6. **聲音**：按清單旁邊的 ▶，聽每個聲音用你的語言講幾句話。這些範例隨程式內建，不花任何費用。

儲存。「系統」頁的檢查清單會列出還缺什麼。

## 4. 準備手機

詳細說明與還原方式：[手機設定](PHONE.md)。簡單來說：

1. 把發行版附的 `pixelcallai_uplink-<version>.zip` 複製到手機，在 Magisk 或 KernelSU App 裡安裝成模組。重新開機。
2. 打開 **Bageo** App，把「設定步驟」一項一項點完，直到每一項都顯示 OK（權限、預設電話 App、來電過濾、勿擾權限、電池最佳化例外）。App 本身不需要 root 權限，這些事由模組代勞。
3. 開啟 **USB 偵錯**（「設定 → 關於手機」→ 連點「版本號碼」七次，再到「系統 → 開發人員選項 → USB 偵錯」）。
4. 把手機接上電腦。在手機上按允許**「允許 USB 偵錯嗎？」**，並勾選「一律允許透過這台電腦進行」。

大約十五秒內，主程式會自己設好 USB 連線，並啟動 App 的通話服務。網頁控制台的「系統 → 手機」會顯示這支手機，先是「已接上」，接著「已連上主程式」。

> 這支手機現在是一台接電話的機器：它不會響出聲音，原本的電話 App 被隱藏，通話時麥克風和喇叭都保持靜音，房間裡的聲音不會被聽到。這是刻意設計的。想暫時當一般手機用，在「系統 → 手機」或 App 裡切成[一般手機模式](PHONE.md#一般手機模式)，隨時都能切回來。

## 5. 第一通電話

用另一支手機撥這支手機的號碼。

- 對方那邊會響一聲（大約三秒，可以調整）。這一聲的時間裡，AI 已經連上並準備好第一句話。
- AI 接起來。跟它聊、打斷它、用另一種語言問它問題，然後說再見。
- 通話結束幾秒後，它會出現在「通話」裡，附上錄音（整通、只有對方、只有 AI）、逐字稿和四行摘要：對方、事情、AI 回覆、要處理。用其他語言講的句子保留原文，下面附上翻譯。

如果沒有人接，請看[疑難排解](TROUBLESHOOTING.md)；「系統」頁通常會告訴你缺了哪一塊。

## 6. 通知

「設定 → 通知 → 新增管道」，選一個服務，填好欄位（每個欄位都有提示怎麼取得），按「**傳送測試**」。可以新增好幾個，每則訊息都會送到全部管道。總共支援 16 種服務，從 Telegram（預約卡片有「同意／不同意」按鈕）到自訂 webhook。各服務的設定方式：[通知](NOTIFICATIONS.md)。

想讓通知裡的連結能打開那通電話，請把控制台對區網開放，見[從其他裝置使用控制台](SETTINGS.md#從其他裝置使用控制台)。之後連結會指向 `http://bageo.local:8787/`（主程式能回應這個名稱時），否則指向電腦的區網位址；「系統 → 關於」會顯示目前用哪一個，並附 QR code。只有在你用其他方式連到這台電腦時（VPN 名稱、反向代理、Docker），才需要設定「這個控制台的網址」。

在你的手機上：先在電腦的控制台打開「系統」，「關於」會顯示控制台網址和 QR code。用手機掃描，再把頁面加到主畫面（iPhone：「分享 → 加入主畫面」；Android：Chrome 選單 ⋮ →「加到主畫面」）。之後點 Bageo 圖示就能打開。

## 7. 聯絡人、行程預約與 AI 代打

接電話用不到這些功能，每一項設定都只要幾分鐘。

### 聯絡人

到「聯絡人 → 匯入」，丟一個檔案進去：從手機匯出的 vCard（`.vcf`）、Google 聯絡人或 Outlook 的 CSV、存成 CSV 或 TSV 的試算表、Excel `.xlsx` 或 Word `.docx` 裡的表格、每行一個名字加號碼的純文字，或是 PDF、名片照片、通訊錄截圖（由 Gemini 辨識）。存檔前每一筆都會先給你看，重複的可以選擇合併或略過。聯絡人的備註（「我妹」「房東」）會在那個人打來時放進 AI 的提示詞。也可以在某通電話的詳細資料裡按「**加入聯絡人**」。

### 行程預約

「設定 → 摘要與行事曆 → 行程預約 → 先問我」就會開啟。來電的人想約時間時，AI 會說確認一下再回覆；通話結束後，這筆預約會出現在「通話」頁最上面的「**待處理事項**」。選好怎麼告訴對方（**傳簡訊**、**AI 回電**或**不通知對方**），再按「**同意**」或「**不同意**」。要傳簡訊的話，得先打開「傳簡訊告訴對方」。第一次在同意的預約上按「**加入行事曆**」時，選你用的行事曆（Google、Outlook.com、Microsoft 365、Apple、Yahoo 或 `.ics`），之後按下去就直接加入。

### 第一次 AI 代打

手機得先接過至少一通電話，主程式才知道它插的是哪張 SIM 卡。接著打開「**AI 代打**」：

1. 在「打給誰」輸入聯絡人名字或號碼。沒有 `+` 的號碼視為你所在國家的號碼；國外號碼請用 `+` 開頭。AI 只會用跟號碼同一國的 SIM 卡撥打。
2. 在「要處理的事」寫清楚要辦什麼、哪些條件可以接受，例如：「訂明天晚上 7 點 4 位，姓王，非吸菸區；7 點沒位子的話 7 點半到 8 點也可以。」
3. 選「用什麼身分打」：你的助理（預設）或你本人。
4. 按開始撥打，並保持頁面開著。你會看到即時字幕；AI 拿不準時，會跳出一張 40 秒倒數的提問卡問你，「告訴 AI」也能隨時交代它。

結果會出現在交辦清單裡，並只發一則通知。結果寫「要你決定」時，從選項挑一個或自己寫回覆，再請 AI 打一次。

## 8. 讓它一直開著

主程式要一直在跑，才接得到電話。

- **Windows：** 把 `start.cmd` 的捷徑放進「啟動」資料夾（`Win+R` → `shell:startup`），或在「工作排程器」建立一個「登入時」執行 `start.cmd -NoBrowser` 的工作。插電時請關閉睡眠。
- **macOS：** 「系統設定 → 一般 → 登入項目」→ 加入 `start.command`；並防止睡眠（「電池／能源 → 防止自動進入睡眠」）。
- **Linux：** 建立一個 systemd 使用者服務：

  ```ini
  # ~/.config/systemd/user/bageo-call.service
  [Unit]
  Description=Bageo agent
  After=network-online.target

  [Service]
  WorkingDirectory=%h/bageo-call
  ExecStart=%h/bageo-call/start.sh --no-browser --yes
  Restart=on-failure

  [Install]
  WantedBy=default.target
  ```

  執行 `systemctl --user enable --now bageo-call` 和 `loginctl enable-linger $USER`，讓它在沒有登入的情況下也會執行。
- **Docker：** `docker-compose.yml` 裡的 `restart: unless-stopped` 已經會在重開機後把它帶起來。

手機請一直接著充電器。手機或電腦重新開機的話，兩邊都會自己重新連上。
