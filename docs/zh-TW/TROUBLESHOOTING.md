# 疑難排解與常見問題

先看網頁控制台的「**系統**」頁：它的檢查清單會指出缺了哪一塊。主程式的終端機視窗會顯示它正在做什麼；在 `.env` 裡設 `RUST_LOG=agent=debug` 可以看到更多。

## 主程式無法啟動

| 你看到的 | 怎麼處理 |
|---|---|
| `cannot listen on 127.0.0.1:8787 … is another copy running?` | 有另一個主程式（或別的程式）佔用了這個連接埠。把它關掉，或在 `.env` 裡設 `AGENT_PORT=8790`。 |
| 「The agent program was not found」（找不到主程式） | 你 clone 了原始碼，但沒有安裝 Rust。請安裝 [Rust](https://rustup.rs) 後再執行一次啟動腳本，或改用發行版的套件。 |
| Windows：「running scripts is disabled」（已停用指令碼執行） | 請用 `start.cmd`（它會用正確的選項啟動 PowerShell），不要直接執行 `start.ps1`。 |
| macOS：「cannot be opened because the developer cannot be verified」（無法打開，因為無法驗證開發者） | 按右鍵 →「打開」，或到「系統設定 → 隱私權與安全性」允許它，或在該資料夾執行 `xattr -dr com.apple.quarantine .`。 |
| 網頁要求輸入存取權杖 | 有設定 `CALLS_UI_TOKEN`：輸入它（瀏覽器會記住），或打開 `http://…:8787/?token=<your token>`。 |

## 手機沒有出現

「系統 → 手機」會告訴你它進行到哪一步。

| 顯示的內容 | 怎麼處理 |
|---|---|
| 找不到 adb | 讓啟動腳本下載 platform-tools、自己安裝，或設定 `ADB_BIN`。 |
| USB 上沒有找到手機 | 線材或 USB 孔的問題（換一個試試；有些線只能充電）。USB 偵錯沒開。在 Windows 上，手機可能需要 Google 的 USB 驅動程式。 |
| `unauthorized` | 解鎖手機，在「允許 USB 偵錯嗎？」視窗按允許。如果視窗沒有跳出來：開發人員選項 →「撤銷 USB 偵錯授權」，再重新插線。 |
| 這支手機還沒安裝 Bageo App | 模組沒有安裝或沒有生效——見[手機設定](PHONE.md)。 |
| 已接上 USB、連線也建立了，但沒有連上主程式 | 打開 Bageo App：最上面的卡片寫什麼？設定步驟每一步都正常嗎？點「**進階 → 測試連線**」。主程式每 90 秒會再試一次啟動服務。 |
| 連上又斷、一再重複 | 電腦上有兩個不同版本的 `adb`（Android Studio、手機投影工具…）一直互相重啟對方。把 `ADB_BIN` 設成其中一個，並關掉另一個工具。 |

## 電話沒有接，或聲音不對

| 症狀 | 可能的原因 |
|---|---|
| 手機一直響個不停 | 手機是[一般手機模式](PHONE.md#一般手機模式)（App 的卡片寫「一般手機」）、App 的服務沒有在執行，或手機沒連上主程式：12 秒內沒連上，App 完全不會接，電話會一直響到電信當成未接來電或轉語音信箱。請看「系統 → 手機」和 App 的卡片。 |
| 接起來就馬上掛斷，什麼都沒說 | AI 啟動不了：沒有 Gemini 金鑰、金鑰錯誤、模型名稱不存在、沒有網路，或控制台裡的「由 AI 接聽來電」是關的。通話紀錄的摘要會寫「AI 沒接上，沒講話」；終端機會顯示 Gemini 的錯誤訊息。 |
| 對方什麼都聽不到，但 AI 看起來有在回答（逐字稿裡有 AI 的句子） | 手機沒辦法把聲音播進通話（不支援的手機，或 App 不是特權 App）。見 [`android/README.md`](../../android/README.md#troubleshooting)（英文）裡的表格。 |
| AI 對對方完全沒反應（逐字稿裡沒有對方的句子） | 手機沒有把通話音訊交給 App——同樣是手機支援度的問題。 |
| AI 自己回答自己／搶對方的話 | 手機的錄音裡含有 AI 自己的聲音，而回音檢查沒有抓到。請關掉「對方可以打斷 AI」。 |
| AI 太早掛斷 | 它的提示詞讓它在對方還沒講完前就說了再見。見[撰寫提示詞](PROMPTS.md#自己寫或修改)裡關於結束的規則。 |
| 電話一直不結束 | 對方始終沒說出主程式認得的道別語，又一直留在線上；要到「一般電話最長」才會結束。常發生的話，把它調短。 |
| 沒人講話的電話大約半分鐘就掛了 | 這是設計好的。對方從頭到尾一句話都沒講時，AI 在自己開口 25 秒後（接起後大約 27 秒）收尾掛斷，口袋誤撥或只聽不講的機器人不會一直佔線。通話中途線上安靜下來時，AI 會在 15 秒後問「還在嗎？」（最多兩次），再過 25 秒結束；對方說過「等一下」時，45 秒後才問、90 秒後才結束。預錄的語音選單 AI 不會回答：線上安靜 4 秒後主程式就掛斷。 |
| 國外來電時 AI 比較晚開口，或跟預錄警語搶話 | 台灣的電信業者會在國外來電播防詐騙警語。台灣 SIM 接到時，AI 會等線路安靜下來（最多 7.5 秒）再說一次開場白。這個沒有設定可調。手機 App 早於 1.0（0.2.4 及更早）時，主程式不知道是哪張卡接的，改看號碼的國碼（[`COUNTRY_CODE`](SETTINGS.md#國際電話國碼)）。 |
| 第二個打來的人說你在忙線 | 這是設計好的：一次只接一通。通話中又打進來的電話會立刻被拒接，留在通話清單裡，並送出「📵 通話中插播未接」通知。 |
| 像 `080*` 這種前綴什麼都沒擋到 | `*` 前面至少要有四碼數字（`0800*`），免得一行太短的規則把整個地區或所有手機號碼都擋掉。號碼請照通話清單裡顯示的樣子寫；`+…` 的寫法只有在知道你的國碼時才對得上。 |
| 第一句話出來得很慢 | 開啟「響鈴時先讓 AI 準備好」，並把「響多久再接」維持在 3 秒以上。 |
| 用錯語言回答 | 「語言」決定開場用的語言（另一張 SIM 的開場看「各 SIM 的語言」）。之後對方明顯講另一種語言時 AI 會跟著換；只有一句很短的「喂？」不會讓它換。 |
| 正常的電話被當成推銷／詐騙 | 關掉「陪他聊、拖時間」，或告訴我們是哪些字觸發的（主程式的終端機輸出會列出來：`stall engaged … hits=[…]`）。 |
| 親友的電話被當成推銷／詐騙 | 把他們存成聯絡人：主程式在開始陪聊前會再看一次，聯絡人講到錢、轉帳、帳單都不會被當成推銷或詐騙。 |

## 行程預約與簡訊

| 症狀 | 怎麼處理 |
|---|---|
| 「待處理事項」寫「簡訊沒傳出：手機沒連線」（`offline`） | 接那通電話的手機現在沒連上。等它連上後按「**重傳簡訊**」，或在那裡改選另一支連著的手機。 |
| 「手機 App 太舊，不支援傳簡訊」（`old_app`） | 在那支手機裝 1.0 版模組（[手機設定](PHONE.md#更新)）。 |
| 「失敗代碼 generic_failure」／`no_service`／`radio_off` | 電信沒收下這則簡訊：沒訊號、飛航模式，或預付卡沒有餘額（很常見的原因：卡片餘額用完了）。在手機上處理好之後按「**重傳簡訊**」。 |
| 某位來電者沒有「傳簡訊」可選 | 市話、免付費、特殊號碼、未顯示號碼和國外號碼收不到簡訊；「預設回覆方式」會改用 AI 回電，連回電也不允許時就不通知（見[設定](SETTINGS.md#摘要與行事曆)）。 |
| AI 回電什麼都沒說 | 它要等對方接起來出聲才講；70 秒都沒人出聲就算 `no_answer`。「待處理事項」會顯示進行到哪一步。 |
| 在網頁決定後，Telegram 卡片還有按鈕 | 按鈕會在決定後幾秒內拿掉；在舊卡片上按只會回「這個預約已經處理過了」。 |

## AI 代打

| 控制台顯示 | 原因與處理方式 |
|---|---|
| 「這支手機還沒接過電話」（`sim_unknown`） | 主程式是從手機回報的來電學到每支手機有哪些 SIM——哪個訂閱 id 是哪個國家的卡——這樣代打才不會用別國的卡打本國號碼（變成昂貴的國際電話，或根本打不通）。裝好後還沒接過任何電話的手機暫時不能用：用任何一支電話打給它一通，再試一次。 |
| 「沒有能打這個國家號碼的手機卡」（`no_sim_for_country`） | 代打只用跟號碼同一個國家的 SIM 撥出。國外號碼請寫 `+` 和國碼；沒有 `+` 就當成本國號碼。 |
| 「這個號碼不能由 AI 撥打」（`not_allowed`） | 緊急號碼、7 碼以下的短碼和加值付費號碼一律不撥；用國際冠碼（`00…`、`011…`）代替 `+` 寫的號碼也不撥。 |
| 「目前沒有可用的 AI 手機」（`no_phone`） | 沒有手機連著，或每支都切成一般手機。到「系統 → 手機」切回一支。 |
| 一直停在「排隊中」 | 手機正在通話，或打給同一個號碼的前一通（代打或預約回電）還沒結束。空出來就會自己撥；等超過 10 分鐘（`phone_busy`），或排在同號碼後面超過 25 分鐘（`number_busy`）就放棄。 |
| 「手機用了別張 SIM 卡撥出…已立刻掛斷」（`wrong_sim`） | 主程式記得的那張卡不見了或換過。打給那支手機一通，讓系統重新認卡，再按「**再打一次**」。 |
| 「需要按鍵的語音選單」（`keypad_menu`） | AI 不能按鍵。它最多等 90 秒等真人；這種號碼請自己打，或找直撥號碼。 |
| 「電信語音：…」（`carrier_message`） | 電信用錄音回應（空號、未開機）。請確認號碼。 |
| AI 問的問題沒出現在頁面上 | 只有你正在看那一筆（6 秒內開著它的即時畫面）時問題才會出現，而且只等 40 秒。否則 AI 會記下對方的選項、客氣收尾；結果是「要你決定」，附上選項讓你選一個請 AI 回電。 |
| AI 訂好了，結果卻寫「要你決定」 | AI 在你沒回答的問題上先做了決定。看一下細節，不合適就按「**再打一次**」並寫清楚要改什麼。 |

## 通知

| 症狀 | 怎麼處理 |
|---|---|
| 「傳送測試」顯示錯誤 | 那段文字就是服務本身的回應——通常是 token、chat ID 或網址填錯。各服務的步驟：[通知](NOTIFICATIONS.md)。 |
| 測試成功，但通話後沒有訊息 | 「傳送通知」是關的，或該管道被停用了。 |
| 沒有摘要，只有對方開頭說的幾句話 | 沒有摘要服務：請設定 Gemini 金鑰（預設就是用它），或在「摘要與行事曆」設定你自己的服務。如果服務拒絕了，終端機會顯示原因。 |
| 通知裡的連結打不開 | 「這個控制台的網址」必須是你手機連得到的位址，而且主程式要在網路上監聽——見[設定參考](SETTINGS.md#從其他裝置使用控制台)。 |
| 行事曆連結打開的不是我用的行事曆 | 在控制台第一次按「加入行事曆」時會問要用哪一家；按鈕旁的「更換」可以改。Apple 日曆／`.ics` 的連結需要填「這個控制台的網址」。 |
| 手機重新開機後，簡訊轉發讀不到簡訊 | Android 在重新開機後、第一次輸入 PIN 解鎖之前，會把簡訊收件匣鎖住（Direct Boot）。解鎖一次就好，轉發工具會自己補上。有裝選用的簡訊 hook 時，第一次解鎖前收到的新簡訊也照樣轉發。見[簡訊轉發工具](../../tools/sms_forward/README.md#troubleshooting)（英文）。 |

## 常見問題

**iPhone 可以用嗎？沒有 root 可以用嗎？**
不行。Android 只允許特權系統 App 錄下通話並把聲音播進通話，iOS 則完全不允許。

**我的（非 Pixel）Android 手機能用嗎？**
要有人試過才知道；這取決於手機的音訊硬體層。見[手機設定](PHONE.md#支援哪些手機)。

**我還能照常使用這支手機嗎？**
暫時用可以：在 App 或網頁控制台把它切成[一般手機](PHONE.md#一般手機模式)，用完再切回來。天天用的話，請用備用手機，或把 SIM 卡移過去（也可以把主要號碼設定來電轉接到備用手機的號碼——這樣你的主要手機會先響，沒接的電話才交給 AI）。你自己用這支手機撥出的電話，永遠不會被靜音或被 AI 接手。

**要花多少錢？**
軟體免費。Gemini Live 音訊由 Google 依用量計費（來電、AI 回電、AI 代打都一樣）；摘要只是送到 Gemini 最便宜模型的一次小小文字請求。試聽聲音和拒接語音都是預先錄好的，不花錢。還要一個能接電話（也能傳 AI 替你發的簡訊、打 AI 替你撥的電話）的門號資費，以及電費。

**可以不用 Google／完全離線執行嗎？**
在受支援的模式下不行：自然、低延遲的語音靠的就是 Gemini Live。摘要可以改用本機模型（Ollama）——見[設定參考](SETTINGS.md#摘要與行事曆)。本機語音管線列在[發展藍圖](ROADMAP.md)裡。

**它能撥出電話或傳簡訊嗎？**
可以。撥電話有兩種：**AI 代打**——你在「代打」頁寫下要辦的事，AI 打過去處理、拿不準時問你、最後回報結果；以及告訴來電者行程預約結果的 **AI 回電**。**傳簡訊**是把你對行程預約的回覆傳給來電者，從那通電話打進來的 SIM 發出。選用的[簡訊轉發工具](../../tools/sms_forward/README.md)（英文）則會把手機收到的簡訊轉到你的通知。

**它能把正在進行的電話轉接到我的手機嗎？**
目前還不行。不支援把通話中的電話即時轉接給真人；AI 會記下留言或把事情辦完，再由你回電。

**多支手機／多個號碼？**
可以：把好幾支手機接到同一台電腦。它們共用同一份設定。

**我的錄音在哪裡？怎麼刪除？**
在 `data/calls/<date>/`。超過 `CALLS_RETENTION_DAYS`（預設 7）天就會被刪除；把資料夾刪掉就全部清除。

**對方會被告知這是 AI 嗎？**
用「AI 助理」方式時，第一句話就會說。用「本人」方式時，只有對方認真問起才會說。後者在你所在的地方是否允許，要由你自己查清楚——見[隱私、安全與法律](PRIVACY_AND_LEGAL.md)。

## 回報問題

開一個 issue，內容包括：你的系統（Windows / macOS / Linux）、手機型號和 Android 版本、主程式版本（在「系統」頁最下方）、你做了什麼、你預期會怎樣，以及主程式終端機輸出裡相關的幾行。請先把電話號碼和金鑰拿掉。絕對不要貼出 `settings.json`。
