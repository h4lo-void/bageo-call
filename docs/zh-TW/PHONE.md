# 手機設定：把 root 過的 Android 手機變成 AI 接電話專用機

手機是 Bageo 通往電話網路的那條線。它插著你的 SIM 卡，無聲接起來電，把對方的聲音即時送給電腦上的 Bageo，再把 AI 的聲音播回通話裡。AI（Gemini Live）由電腦上的 Bageo 負責，手機本身不做任何 AI 運算。

這一頁說明：

- 哪些手機能用
- 怎麼安裝 root 模組
- 怎麼用 USB 或 Wi-Fi 連到電腦
- 怎麼在 AI 接聽和一般手機之間切換
- 怎麼全部還原

建置 App、它的權限與通訊協定，寫在 [`android/README.md`](../../android/README.md)（英文）。

這一頁說明的是 **Bageo 1.6**：root 模組 `v1.6.9`（versionCode 25），裡面的 App 是 `1.6.9`（versionCode 33），安裝檔是 `bageo-phone-module-1.6.9.zip`。App 的版本在它的「進階」畫面看得到，控制台則在「系統 → 手機」。

## 手機會做哪些事

| 工作 | 怎麼做 |
|---|---|
| 無聲接聽來電 | 照 Bageo 設定的時間讓電話響（預設 3 秒），無聲接起，並在通話和電腦上的 Bageo 之間傳送雙方的聲音。手機旁邊的人兩邊都聽不到。 |
| 在 AI 接聽和一般手機之間切換 | App 裡一個開關，或控制台一個按鈕。App 本身不需要 root 權限，改系統設定的是模組的 root 小幫手。見[一般手機模式](#一般手機模式)。 |
| 不碰你自己打的電話 | 你自己撥出的電話不會接 AI，麥克風和聽筒照常能用，講完後手機會再恢復靜音。只有打進來的電話，和 Bageo 要求撥出的電話（AI 回電、AI 代打）才會接上 AI。 |
| 替你傳簡訊 | 你回覆行程預約、選擇用簡訊通知時，由接那通電話的手機用自己的號碼傳出（`send_sms`）。 |
| 替 Bageo 撥電話 | 告訴對方預約結果的 AI 回電，以及你在控制台「AI 代打」頁交辦的電話（`place_call`）。手機在響或通話中時不會撥號，新的電話會等它空下來（代打最多等 10 分鐘）。 |
| 選對 SIM 卡 | 雙卡手機傳簡訊、撥電話時，用 Bageo 指定的 Android 訂閱 id（`sub_id`）那張卡。回電用原本那通電話打進來的卡，代打用跟號碼同一國的卡。 |
| 一次只接一通 | 通話中又有第二通打進來，會立刻拒接（對方聽到忙線），並回報 Bageo（`call_waiting_rejected`）。通話清單會留下紀錄，你也會收到「通話中插播未接」通知。 |
| 出狀況時安全收場 | 響鈴時連不到電腦上的 Bageo：不接，交給電信當未接來電或轉語音信箱。通話中跟電腦上的 Bageo 斷線 3 秒：直接掛斷，不讓對方對著一片安靜。 |

## 支援哪些手機

- **實測過：** Google Pixel 7、7a、8、9，以 Magisk 或 KernelSU root。
- **Android 10 或更新版本。**
- **其他手機：風險自負。** App 需要手機開放兩件事，很多手機連特權 App 都不給：通話中錄下對方的聲音，以及把聲音播「進」通話裡。缺一樣，電話會被接起來，但有一方什麼都聽不到。目前還沒有其他可用機型的清單；如果你試了，歡迎回報結果。

不同手機還有一項差異，Bageo 會在每通電話一開始自己測：手機的通話錄音裡，會不會錄到 AI 自己的聲音。

| 通話錄音 | 會有什麼不同 | 實測機型 |
|---|---|---|
| 錄不到 AI 的聲音 | AI 講話時對方可以插話，背景音整通電話持續播放。 | Pixel 9 |
| 錄得到 AI 的聲音 | AI 會把自己的聲音從聽到的內容裡濾掉，所以它會先把句子講完才繼續聽，背景音也只在 AI 講話時播放。 | Pixel 7、7a |

## 請用備用手機

裝好模組後，手機就成了一台接電話專用機：

- Bageo 成為預設電話 App 和來電過濾 App，Google 的電話 App 被停用，所以不會出現通話畫面。
- 勿擾模式打開，鈴聲和通知音量歸零。
- 通話時麥克風靜音、喇叭關閉、聽筒音量調到最小：房間裡的聲音不會被收進去，也不會有聲音播出來。

你還是可以用別的撥號 App 打電話出去，但它已經不適合當日常手機。以上這些都能從 App 或控制台關掉（見[一般手機模式](#一般手機模式)），也能徹底還原（見[還原](#還原)）。

## 安裝

1. 用 Magisk 或 KernelSU 把手機 **root**（這裡不說明）。
2. 如果你曾經把這個 App 當一般 APK 安裝過，請先解除安裝。兩種絕對不要同時存在。
3. 把 `bageo-phone-module-<version>.zip` 複製到手機（這一版是 `bageo-phone-module-1.6.9.zip`）。在 Magisk 或 KernelSU App 裡：「模組」（Modules）→「從本機安裝」（Install from storage）→ 選那個 zip → 重新開機。
4. 打開 **Bageo**。最上面的卡片用一句話說明手機現在的狀態。下面的「**設定步驟**」列出還沒完成的事，每一步都有按鈕：

   | 步驟 | 要做什麼 |
   |---|---|
   | 安裝 Bageo 模組 | 重新開機後就會完成。沒有的話，表示模組沒有生效。 |
   | 允許 Bageo 使用電話和麥克風 | 按「**允許**」（麥克風、電話、通話紀錄、通知）。 |
   | 把 Bageo 設成預設電話 App | 按「**設定**」。 |
   | 把 Bageo 設成來電過濾 App | 按「**設定**」。 |
   | 允許 Bageo 控制勿擾模式 | 按「**開啟設定**」並允許。 |
   | 不要讓 Bageo 進入休眠 | 按「**允許**」，Android 才不會把服務停掉。 |
   | 插入電腦完成第一次配對 | 開啟 USB 偵錯，用 USB 線接到執行 Bageo 的電腦配對一次；之後拔掉線也能用 Wi-Fi 連線。沒辦法插 USB（例如 Bageo 裝在 Docker）：點「**用 IP 位址連線**」（見 [Wi-Fi](#wi-fi)）。 |

   步驟全部完成後清單會自動收起；手機連上電腦後，卡片會顯示「AI 正在幫你接電話」。連線位址、測試連線和詳細檢查都在「**進階**」裡。

   App 本身不需要 root 權限（root 的工作由模組做），所以 root 管理程式若詢問，允許或拒絕都可以。

   設定畫面不會跟你要傳簡訊的權限（`SEND_SMS`）：模組會在開機時、以及每次切到 AI 模式時授予。雙卡手機選卡和撥號一律用訂閱 id，而 `READ_PHONE_NUMBERS` 權限只用來讀取門號回報給 Bageo（如果電信商隱藏號碼，也能在控制台的「手機」分頁手動填入）。
5. 讓「**AI 幫我接電話**」保持開啟。

### 更新

用同樣的方式（「從本機安裝」）把新的 zip 裝在舊模組上，再重新開機。你選的模式、連線位址和 App 的權限都會保留。這個專案發行的版本都用專案自己的金鑰簽署，可以直接覆蓋安裝；如果要在發行版和自己建置的版本之間切換，請先移除模組並重新開機（見 [`android/README.md`](../../android/README.md#build)，英文）。

## 連接到電腦

### USB（建議）

1. 在手機上：「設定 → 關於手機」，連點「版本號碼」七次；再到「系統 → 開發人員選項」開啟 **USB 偵錯**。
2. 把手機接到執行 Bageo 的那台電腦。
3. 在手機上的「**允許 USB 偵錯嗎？**」按允許（勾選「一律允許」）。

這樣就好了。Bageo 會找到手機，把 App 的本機位址（`ws://127.0.0.1:8765`）透過 USB 線對應到電腦上，並啟動 App 的服務。它每 15 秒檢查一次，所以拔掉再插回去、或任何一邊重新啟動，都會自己恢復。

USB 還能讓手機一直充電，沒有 Wi-Fi 也能用。一台電腦可以接好幾支手機，每支各自接聽自己的號碼。

### Wi-Fi

手機用 USB 接過一次（見上一節）就配對好了：Bageo 會把自己的 Wi-Fi 位址和配對金鑰交給手機。之後拔掉線，手機會自己改用 Wi-Fi 連回來；再插上線就又走 USB。「系統」頁會標出每支手機現在是用 USB 還是 Wi-Fi 連線。

- 手機和電腦要在同一個網路。
- Windows 第一次配對時，防火牆會問要不要讓 Bageo 使用網路，請在「**私人網路**」按允許。
- 手機連的是 8788 埠（`PHONE_WIFI_PORT`；Bageo 用 `AGENT_HOST=0.0.0.0` 對網路開放時是 8787）。手機先試電腦的 IP 位址，區網名稱開著時再試 `bageo.local`。
- 「設定 → 進階」的「**手機也能用 Wi-Fi 連**」可以關掉這個功能，用 Wi-Fi 的手機會馬上斷線。「**重新配對手機**」會換一組新的配對金鑰，手機遺失時使用；之後每支用 Wi-Fi 的手機都要再用 USB 接一次。
- 配對金鑰只會傳給已經連上的手機，或輸入正確配對碼的手機，不會出現在控制台、通知或紀錄裡。
- 舊版 App 不認得配對，會繼續只走 USB。
- 用 Docker 或手機完全插不上 USB 時，照下面用 IP 位址配對。

**用 IP 位址配對。** Bageo 裝在 Docker 或另一台電腦、手機插不上 USB 時用。

1. 控制台打開「系統」頁，在「**用 IP 位址配對手機**」按「**產生配對碼**」。配對碼 10 分鐘內有效，只能用一次。
2. 手機的 Bageo App 點「**用 IP 位址連線**」（狀態卡、設定步驟和「進階 → 連線」都有），輸入 Bageo 的 IP 位址和埠（例如 `192.168.1.20:8787`）以及配對碼。

手機會記住這個位址，重開機後自己連回來。手機和控制台用同一個埠（沒改過就是 8787）；Docker 主機上的埠換成別的號碼也可以，手機輸入的位址就填你對外開的那個埠。手機和 Bageo 要在同一個網路，「**手機也能用 Wi-Fi 連**」要開著。再產生一次會換掉舊的配對碼，輸錯 5 次那組就作廢。「**重新配對手機**」也會讓這樣配對的手機斷線，要用新的配對碼再配一次。

**手動填網址。** 手機完全沒辦法用線接到電腦時，用這個方式。

1. 讓 Bageo 能從網路連進來，並要求密碼：在 `.env` 設定 `AGENT_HOST=0.0.0.0`、`DEVICE_TOKEN=<一長串隨機字元>`（手機連線用）和 `CALLS_UI_TOKEN=<另一長串>`（控制台密碼），見[設定參考](SETTINGS.md)。
2. 在 App 的「進階 → 連線」輸入 `ws://<電腦的位址>:8787/ws?token=<DEVICE_TOKEN>`，然後儲存。「**測試連線**」會告訴你連不連得上；連不上時會用白話說原因，原始錯誤訊息在「詳細資訊」裡。

這條連線沒有加密（`ws://`）：只在你自己的網路裡使用，或在前面架一個 TLS 反向代理並改用 `wss://`。通話走 USB 會比較穩。

## 日常使用

- 服務執行時，App 會顯示一則不吵人的常駐通知；重新開機後也會自己啟動。
- 想暫時自己用這支手機，把它切成[一般手機](#一般手機模式)。
- 想讓所有手機的 AI 一起停，到控制台「基本設定」關掉「由 AI 接聽來電」（電話會被接起來再掛斷）。
- 雙卡手機會告訴 Bageo 每通電話打到哪一張 SIM。Bageo 依「各 SIM 卡的主要語言」（在「基本設定」的「更多選項」）決定開場語言，簡訊和回電也從同一張卡發出。
- AI 代打要先知道手機有哪些 SIM。1.4 以上版本的手機 App 連線時會自動上報所有 SIM 卡（只有舊版 App 才需要在第一次代打前先打一通電話給它）。
- Bageo 有控制台網址時，App 會出現「**打開網頁控制台**」按鈕。網址取自「通知」頁的「通知裡的網址」；沒填而控制台對區網開放時，自動用電腦的區網位址。

## 一般手機模式

手機有兩種模式，除了通話中以外隨時可以切換：

| 模式 | 會怎樣 |
|---|---|
| **AI 幫我接電話**（預設） | 就是[請用備用手機](#請用備用手機)說的接管狀態。從沒切換過的手機，更新後也維持這個模式。 |
| **一般手機** | 來電會正常響，由你自己接。AI 不接、沒有東西被靜音，Google 的電話 App 也回來了。 |

**在手機上切換：** 打開 Bageo，把最上面的大開關「**AI 幫我接電話**」關掉或打開。確認後等幾秒，卡片會顯示「一般手機：來電會正常響」，或顯示 AI 又在接電話了。

**從控制台切換：** 「系統 → 手機」。每支連上的手機會顯示名稱、App 版本、目前模式和一個按鈕：「**改成一般手機**」（會先跳確認框）或「**改回 AI 接聽**」。App 比這個功能舊的手機不會有按鈕，而是顯示「這支手機的 Bageo App 要更新，才能從這裡切換」。

### 切換時改了什麼

切成**一般手機**會依序改這些系統設定：

1. Bageo 不再是來電過濾 App，來電不會再被靜音。
2. 關掉勿擾模式。
3. 鈴聲模式改回正常；鈴聲、通知、聽筒、媒體、鬧鐘、系統音量還原成這支手機上次切到 AI 模式前的數值。沒存過、或存的是 0 的，就用最大值的一半。
4. 麥克風不再被靜音，聽筒音量也不再被釘在最小。
5. 最後才重新啟用 Google 電話（`com.google.android.dialer`），並設成預設電話 App。沒有 Google 電話的手機，Bageo 會把這個角色讓出來，由 Android 用內建的電話 App。要確認 Google 電話真的成了預設電話 App、而且沒有被停用，這次切換才算完成。

這些設定由模組以 root 身分來改：模組每次開機會啟動一個小幫手，App 要切換時就由它執行，所以 App 不需要 root 權限。Android 把某個 App 的電話角色拿走時，可能會順便把它關掉；小幫手不受影響，會把設定改完，所以換電話 App 放在最後一步。

一般手機模式下，Bageo 的服務會繼續執行、保持連線，讓你能從控制台切回來，但它不會接、不會靜音、也不會碰任何一通電話。控制台會把這支手機顯示成一般手機，`/health` 的 `normal_mode_serials` 也會列出它。

切回「**AI 幫我接電話**」時，會先存下目前的音量，再重做一次模組的接管：Bageo 成為電話 App 和來電過濾 App、停用 Google 的電話 App、打開勿擾模式、音量歸零。

### 切換沒完成時

- App 和控制台會說是哪一步失敗（例如「手機沒辦法更換預設電話 App」）。再切一次會把每一步重做一遍；切換還沒完成時，App 下次啟動（例如重新開機後）也會自己重做。
- 如果 App 說 Bageo 模組沒有在執行，請在 Magisk 或 KernelSU 確認 **Bageo Uplink** 模組已啟用，然後重新開機。
- 切成一般手機時 App 說「勿擾還開著」：到手機的「設定 → 模式」，把 App 點名的那個模式關掉（例如「零打擾 (Bageo)」或「就寢時間」），再切一次。這種情況 App 不會自己重試。Android 15 以上，1.4.0 和更早的 App 會自己開一個用 Bageo 命名的模式，模組關不到它；新版 App 不再開，切成一般手機前也會先把它關掉。
- 控制台 15 秒內沒收到手機回覆時，會顯示「結果未確認，請稍後重新整理。」，稍後重新整理就會看到手機回報的模式。

### 模式存在哪裡

模式存在 `/data/adb/pixelcallai/mode`（內容是 `ai` 或 `normal`），在模組資料夾外面，所以重新開機、更新模組都不會不見。模組每次開機都會讀它；檔案不存在就是 AI 模式。

上一次切換的結果在同一個資料夾的 `last_apply`，切換還沒完成時會有 `pending` 這個檔案。一般手機模式要還原的音量，存在 App 自己的資料夾裡。

### 用 adb 切換

不碰手機畫面、用電腦的 `adb` 切換：

- 馬上切換，不用重新開機（App 會一次把整個切換做完）：

  ```text
  adb shell am start-foreground-service -n com.pixelcallai.streamer/.CallAudioService -a com.pixelcallai.streamer.SET_ENABLED --ez enabled false
  ```

  改成 `--ez enabled true` 就切回「**AI 幫我接電話**」。
- 寫入模式檔再重新開機（App 的服務啟動時會把其他設定補上）：

  ```text
  adb shell "su -c 'mkdir -p /data/adb/pixelcallai && echo normal > /data/adb/pixelcallai/mode'"
  adb reboot
  ```

  切回 AI 模式：改寫成 `ai`（`echo ai > …`），或用 `adb shell "su -c 'rm -f /data/adb/pixelcallai/mode'"` 刪掉這個檔案，再重新開機。

## 還原

要移除 Bageo：

1. 先把手機切成[一般手機](#一般手機模式)。這會把 Google 的電話 App、鈴聲和音量都還原，並關掉勿擾模式，第 3、4 步就不用做了。
2. 在 Magisk 或 KernelSU 停用或移除 **Bageo Uplink** 模組，然後重新開機。

   如果手機開機開不到那一步，請用 root 管理程式的安全模式，或在 recovery 裡以 root 執行：`touch /data/adb/modules/pixelcallai_uplink/disable`。

   放模式檔的 `/data/adb/pixelcallai/` 資料夾會留著；以後不打算再裝 Bageo 的話，也把它刪掉。
3. 如果沒先切換就移除了模組：移除模組**不會**把 Google 的電話 App 帶回來，也不會關掉勿擾模式，因為這兩樣 Android 都會記住。重新啟用電話 App：

   ```text
   adb shell su -c "pm enable com.google.android.dialer"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallServiceImpl"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallActivity"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.LegacyInCallActivity"
   adb shell su -c "cmd role add-role-holder android.app.role.DIALER com.google.android.dialer"
   adb shell su -c "telecom set-default-dialer com.google.android.dialer"
   ```

4. 到系統設定關掉勿擾模式，並把音量調回來。
