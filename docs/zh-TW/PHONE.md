# 手機設定

手機是通往電話網路的閘道：它插著你的 SIM 卡，無聲地接起來電，把對方的聲音送給主程式，再把 AI 的聲音播進通話裡。它本身不做任何 AI 運算。

關於建置 App、它的權限與通訊協定，全部寫在 [`android/README.md`](../../android/README.md)（英文）。這一頁是從使用者的角度來看。

## 支援哪些手機

- **實測過：Google Pixel 7、7a、8、9**，以 Magisk 或 KernelSU root。
- **其他手機：風險自負。** App 需要手機的音訊硬體層提供兩件事，而很多手機並不開放給 App，即使是特權 App 也一樣：在通話中錄下對方的聲音，以及把聲音播「進」通話裡。只要缺一樣，電話會被接起來，但有一方什麼都聽不到。目前還沒有其他可用機型的清單——如果你試了，請回報結果。
- Android 10 或更新版本。

有一項行為會因手機而異，主程式會在每通電話一開始自己判斷。如果手機的通話錄音裡不含 AI 自己的聲音（我們實際使用的 Pixel 9），對方可以在 AI 講話時插話，背景音也會整通電話持續播放。如果含有（我們實際使用的 Pixel 7 和 7a），AI 自己的聲音會從它聽到的內容裡濾掉，所以它會先把句子講完才繼續聽，背景音也只在 AI 講話時播放。

## 請用備用手機

安裝模組之後，手機會變成一台專門接電話的機器：

- App 會成為預設電話應用程式和來電過濾應用程式，Google 的電話 App 會被停用（不會出現通話畫面）；
- 「零打擾」會開啟，鈴聲和通知音量歸零；
- 通話中麥克風靜音、喇叭關閉、聽筒音量調到最小——房間裡的聲音不會被聽到，也不會有任何聲音播出來。

你還是可以用另一個撥號 App 從這支手機打電話出去，但別期待它像一般手機那樣好用。以上這些都可以從 App 或網頁控制台關掉（見[一般手機模式](#一般手機模式)），也可以徹底復原（見[還原](#還原)）。

## 安裝

1. 把手機 **root**（Magisk 或 KernelSU）。這裡不說明。
2. 如果你曾經把這個 App 當一般 APK 安裝過，請先解除安裝。絕對不要兩種同時存在。
3. 把 `pixelcallai_uplink-<version>.zip` 複製到手機，打開 Magisk 或 KernelSU App →「模組」（Modules）→「從本機安裝」（Install from storage）→ 選那個 zip → 重新開機。
4. 打開 **Myna**。最上面的卡片用一句話說明手機現在的狀態。下面的「**設定步驟**」列出還沒完成的事，每一步都有一個按鈕：

   | 步驟 | 要做什麼 |
   |---|---|
   | 安裝 Myna 模組 | 重新開機後就會完成。如果沒有，表示模組沒有生效。 |
   | 允許 Myna 使用電話和麥克風 | 「**允許**」（麥克風、電話、通話紀錄、通知）。 |
   | 把 Myna 設成預設電話 App／來電過濾 App | 「**設定**」。 |
   | 允許 Myna 控制勿擾模式 | 「**開啟設定**」並允許。 |
   | 不要讓 Myna 進入休眠 | 「**允許**」，Android 才不會把服務停掉。 |

   Root 管理程式詢問時，請允許 root。步驟全部完成後清單會自動收起；手機連上電腦後，卡片會顯示「AI 正在幫你接電話」。連線位址、測試連線和詳細檢查都在「**進階**」裡。
5. 讓「**AI 幫我接電話**」保持開啟。

## 連接到電腦

### USB（建議）

1. 在手機上：「設定 → 關於手機 →」連點「版本號碼」七次；然後到「系統 → 開發人員選項 →」開啟 **USB 偵錯**。
2. 把手機接到執行主程式的那台電腦。
3. 在手機上的「**允許 USB 偵錯嗎？**」視窗按允許（勾選「一律允許」）。

這樣就好了。主程式會找到手機，把 App 的本機位址（`ws://127.0.0.1:8765`）透過 USB 線對應到自己身上，並啟動 App 的服務。它每十五秒檢查一次，所以拔掉再插回去、或任何一邊重新啟動，都會自己恢復。USB 還能讓手機保持充電，沒有 Wi-Fi 也能用。

一台電腦可以接好幾支手機；每支手機各自接聽自己的號碼。

### Wi-Fi

手機沒辦法用線接到電腦時，才用這個方式。

1. 啟動主程式時，讓它在網路上監聽並要求權杖：在 `.env` 裡設定 `AGENT_HOST=0.0.0.0`、`DEVICE_TOKEN=<a long random string>` 和 `CALLS_UI_TOKEN=<another one>`（兩個各填一長串不同的隨機字元；見[設定參考](SETTINGS.md)）。
2. 在 App 的「進階 → 連線」輸入 `ws://<computer's address>:8787/ws?token=<DEVICE_TOKEN>`（其中 computer's address 換成電腦的位址），然後儲存。「**測試連線**」會告訴你連不連得上；連不上時會用白話說原因，原始錯誤訊息在「詳細資訊」裡。

這條連線沒有加密（`ws://`）：只能在你自己的網路裡使用，或在前面架一個 TLS 反向代理並改用 `wss://`。通話走 USB 會比較穩定。

## 日常使用

- 服務執行時，App 會顯示一則不打擾的常駐通知；重新開機後也會自己啟動。
- 想暫時自己用這支手機，就把它切成[一般手機](#一般手機模式)。想讓所有手機的 AI 一起停，在網頁控制台關掉「由 AI 接聽來電」（電話會被接起來再掛斷）。
- 你自己用這支手機撥出去的電話，App 不會介入。
- 主程式知道控制台網址後（設定裡的「這個控制台的網址」），App 會出現「**打開網頁控制台**」按鈕。

## 一般手機模式

手機有兩種模式，除了通話中以外隨時可以切換：

- **AI 幫我接電話**（預設）：就是[請用備用手機](#請用備用手機)說的接管狀態。從沒切換過的手機，更新後也維持這個模式。
- **一般手機**：來電會正常響，由你自己接。AI 不接、沒有東西被靜音，Google 的電話 App 也回來了。

**在手機上切換：** 打開 Myna，把最上面的大開關「**AI 幫我接電話**」關掉或打開。確認後等幾秒，卡片就會顯示「一般手機：來電會正常響」（或 AI 又開始接電話）。

**從網頁控制台切換：** 「系統 → 手機」。每支連上的手機會顯示名稱、App 版本、目前模式和一個按鈕：「**改成一般手機**」或「**改回 AI 接聽**」。改成一般手機前會先跳出確認框。App 比這個功能舊的手機，會顯示「這支手機的 Myna App 要更新，才能從這裡切換」，不會有按鈕。

切成**一般手機**會改這些系統設定：

1. 重新啟用 Google 電話（`com.google.android.dialer`），並設成預設電話 App。沒有 Google 電話的手機，Myna 會把這個角色讓出來，由 Android 用手機內建的電話 App。
2. Myna 不再是來電過濾 App，來電不會再被靜音。
3. 關掉勿擾模式。
4. 鈴聲模式改回正常；鈴聲、通知、聽筒、媒體、鬧鐘、系統音量還原成這支手機上次切到 AI 模式前的數值。沒存過、或存的是 0 的，就用最大值的一半。
5. 麥克風不再被靜音，聽筒音量也不再被釘在最小。

Myna 的服務會繼續執行、保持連線，讓你能從網頁控制台切回來，但它不會接、不會靜音、也不會碰任何一通電話。網頁控制台會把這支手機顯示成一般手機，`/health` 的 `normal_mode_serials` 也會列出它。

切回「**AI 幫我接電話**」時，會先把目前的音量存起來，再重做一次模組的接管：Myna 成為電話 App 和來電過濾 App、停用 Google 電話的通話畫面、打開勿擾、音量歸零。

切換做到一半失敗時，App 和網頁控制台都會說是哪一步沒成功（例如「沒辦法更換預設電話 App」）。再切一次會把每一步重做一遍。切換需要 root，Root 管理程式詢問時請允許。

模式存在 `/data/adb/pixelcallai/mode`（內容是 `ai` 或 `normal`），在模組資料夾外面，所以重新開機、更新模組都不會不見。模組每次開機都會讀它；檔案不存在就是 AI 模式。一般手機要還原的音量存在 `/data/adb/pixelcallai/normal_audio`。不透過 App 畫面切換的話，寫入模式後重新開機，App 的服務啟動時會把其他設定補上：

```text
adb shell su -c "mkdir -p /data/adb/pixelcallai && echo normal > /data/adb/pixelcallai/mode"
adb reboot
```

## 還原

1. 先把手機切成[一般手機](#一般手機模式)。這會把 Google 的電話 App、鈴聲和音量都還原，並關掉勿擾，第 3、4 步就不用做了。
2. 在 Magisk / KernelSU 裡停用或移除 **Myna Uplink** 模組，然後重新開機。如果手機開機開不到那一步，請用 root 管理程式的安全模式，或在 recovery 裡以 root 執行：`touch /data/adb/modules/pixelcallai_uplink/disable`。模式檔所在的 `/data/adb/pixelcallai/` 會留著；以後不打算再裝 Myna 的話，把這個資料夾也刪掉。
3. 如果沒先切換就移除了模組：移除模組**不會**把 Google 的電話 App 帶回來，也不會關掉「零打擾」——這些 Android 都會記住。重新啟用電話 App：

   ```text
   adb shell su -c "pm enable com.google.android.dialer"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallServiceImpl"
   adb shell su -c "pm enable com.google.android.dialer/com.android.incallui.InCallActivity"
   adb shell su -c "cmd role add-role-holder android.app.role.DIALER com.google.android.dialer"
   adb shell su -c "telecom set-default-dialer com.google.android.dialer"
   ```

4. 到系統設定關掉「零打擾」，並把音量調回來。
