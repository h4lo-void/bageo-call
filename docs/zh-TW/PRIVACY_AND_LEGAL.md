# 隱私、安全與法律

本文不是法律意見。這是你讓機器替你接電話之前應該知道的事。

## 你的資料去了哪裡

| 什麼 | 放在哪裡 | 還有誰看得到 |
|---|---|---|
| 通話錄音、逐字稿、摘要 | 你電腦上的 `data/calls/`。預設 7 天後刪除（`CALLS_RETENTION_DAYS`）。 | 沒有別人，除非你把控制台開放給其他人。 |
| 設定、API 金鑰、通知用的 token | `data/calls/config/settings.json`，**以明文儲存**。 | 任何能讀到那個檔案的人。請保護好電腦；絕對不要分享這個檔案。 |
| 每通電話的即時音訊（雙向），加上提示詞和你的資料 | 通話期間送到 **Google 的 Gemini Live API**。 | Google，依你的金鑰和所在地區適用的 Gemini API 條款處理。 |
| 通話的逐字稿 | 通話結束後送到**摘要模型**：預設是 Google，或你設定的服務。開啟行事曆建議時會再送一次。 | 該服務。使用本機模型（Ollama）的話，就留在你的機器上。 |
| 摘要和來電號碼 | 送到你設定的**每一個通知管道**。 | 那些服務，以及那些聊天室裡的所有人。 |
| 設定頁的聲音試聽範例、「無法接通」語音 | 透過 Gemini 產生一次，之後快取在本機。 | Google。 |

主程式不會連到其他任何地方：沒有遙測、不檢查更新、不需要帳號。啟動腳本會在你同意的情況下從 Google 下載 `adb`。

**你的來電者並沒有選擇這一切。** 他們的聲音會送到 Google，他們說的話會送到上面那些服務。請把錄音和逐字稿當作別人的個人資料來對待：保留期間設短一點、不要隨便轉傳，也不要讓控制台能從網際網路連進來。

## 通話錄音

你能不能錄下通話，取決於你和來電者所在的地方。大致上：

- 有些地方，只要通話的**其中一方**（你）知情就夠了——例如美國聯邦法律和美國大多數的州；在台灣，錄下自己參與的對話、且不是出於不法目的時也是如此。
- 另一些地方，通話中的**每一個人**都必須被告知或必須同意——例如包括加州在內的幾個美國州，以及德國。
- 在歐盟和英國，只要用途不是純粹個人性質，資料保護法規（GDPR）就適用：你需要有合法依據，而且必須告知對方。

如果你不確定自己能不能在不告知的情況下錄音：請使用「AI 助理」接聽方式，並在提示詞的開場白裡加一句關於錄音的話（「…這通電話會錄音，以便我轉達您的留言」），或維持 `CALLS_RETENTION_DAYS=1`。商業用途的規定也不一樣。

## 讓 AI 跟人講話

- 「**AI 助理**」方式會在第一句話就說明對方是在跟 AI 講話。這是預設、也是建議使用的方式。
- 「**本人**」方式會讓來電者以為是在跟你講話。主程式一定會加上一條提示詞無法移除的規則：有人**認真問**他是不是在跟真人講話時，AI 會說這是你設定的 AI 語音。在法律要求事先告知的地方，這樣可能不夠（關於機器人和 AI 透明度的法律正在增加——例如加州針對商業與選舉情境的機器人揭露法，以及歐盟《人工智慧法》（AI Act）對與人互動的系統所規定的透明義務）。只有在你確信合法的地方才使用「本人」方式，而且絕不要用在商務電話上。
- 絕不要用它來為了獲利而欺騙別人、冒充他人，或騷擾來電者。用「陪他聊、拖時間」拖住詐騙來電，針對的是明顯屬於推銷或詐騙企圖的電話；偵測是以關鍵字為基礎，可能會出錯——這時真正的來電者會遇到一個反應奇慢、問東問西的人。請檢查摘要；有疑慮就把它關掉。

## AI 會做和不會做的事

每一份提示詞都內建了這些：它不答應付款、合約或約定時間，不給出密碼、驗證碼或個人資料，不替你做任何承諾，也不服從來電者的指令（「忽略你的規則」）。這些是給語言模型的指示，不是保證。你寫進「AI 可以回答的資料」裡的任何內容，都可能被講給**任何**來電者聽——不要放任何機密在裡面。

不要依賴它處理緊急狀況，或你承擔不起漏接的電話。AI 可能聽錯，網路可能斷線，手機可能失去 USB 連線。AI 無法啟動時，主程式會直接掛斷，而不是讓對方面對一片沉默，並且會在通知裡告訴你。

## 保護你的安裝環境

- 預設情況下，主程式只在自己這台電腦上監聽。如果你把它開放給你的網路（`AGENT_HOST=0.0.0.0`），請設定 `CALLS_UI_TOKEN` **以及** `DEVICE_TOKEN`——沒有設的話，那個網路上的任何人都能聽你的通話、看到你金鑰的提示、修改提示詞，或假裝成手機連進來。
- 絕對不要把這個連接埠暴露在網際網路上。控制台只有一組共用的權杖，沒有使用者帳號，而且走未加密的 HTTP。請用 VPN。
- 從這台電腦本身連進來的連線會被當作 USB 上的手機，不需要 `DEVICE_TOKEN`。在同一台電腦上執行的反向代理，會讓每個訪客看起來都像本機：如果你用了反向代理，不要讓它把 `/` 和 `/ws` 的 WebSocket 升級請求轉送給你不信任的人。
- Root 模組讓 App 對手機的通話和音訊擁有很大的控制權。只安裝你信任的版本：這個 repository 的發行版，或你自己建置的版本。
- 已 root 且 bootloader 已解鎖的手機，一旦遺失或被偷，會比較容易被動手腳。請把這支專門接電話的手機留在家裡；它裡面有你的 SIM 卡。
- 安全性問題請私下回報——見 [SECURITY.md](../../SECURITY.md)（英文）。

## 你的 SIM 卡與電信業者

請查看你的電信業者對自動接聽的條款。這些通話就是你門號上一般的來電：這套軟體不會產生額外費用，但漫遊和高額付費號碼的規定照常適用。
