# 發展藍圖

Bageo 1.0 對照大家對開源電話助理的期待做到了哪裡，以及接下來值得做什麼。這裡沒有任何承諾；歡迎發 pull request。

## 這個專案哪裡不一樣

大多數開源電話總機都需要 SIP 線路或雲端電話帳號。Bageo 接的是**你本來就有的 SIM 卡**，用你桌上的一支手機，搭配語音對語音模型：沒有號碼要租，延遲和插話處理由模型負責，而不是靠語音轉文字、LLM、文字轉語音串成的一條鏈。從 1.0 開始，同一支手機也能用你自己的號碼替你打電話。

## 對照社群需求的現況

✅ 已經有 · 🟡 部分有 · ❌ 還沒有

### 接聽來電

| 需求 | 現況 |
|---|---|
| 全天候接聽、自由對話而不是按鍵選單 | ✅ |
| 低延遲 | ✅ 語音對語音；手機還在響時就準備好開場白（實測從接起算中位數約 0.43 秒）。 |
| 真正的插話（barge-in） | ✅ 在收音不含 AI 自己聲音的手機上（我們用的 Pixel 9），每通電話自動偵測；其他手機 AI 會先講完那一句。 |
| 安靜處理 | ✅ 先問對方還在不在，再結束通話。 |
| 語音偵測、雜音 | ✅ 用 Gemini 的，或本機偵測器。 |
| 自然的環境感 | ✅ 12 種背景音、三段音量。 |
| 騷擾與機器人電話 | ✅ 拒接號碼；三道防線（回覆白名單、加權關鍵字、語意複審），再選客氣婉拒或陪聊模式。 |
| 認得常打來的人 | 🟡 通訊錄讓 AI 知道來電者的名字和你的備註。同一個號碼之前的摘要還不會放進提示詞。 |
| 依知識庫回答、不亂編 | 🟡 「AI 可以回答的資料」：放在提示詞裡的純文字，加上「不要猜」的規則。沒有文件搜尋。 |
| 揭露 AI 身分、錄音告知 | 🟡 「AI 助理」身分內建揭露，「本人」身分被認真問到時一定承認。錄音告知要寫在你的提示詞裡。 |
| 防提示詞注入 | 🟡 每份提示詞都有固定規則；沒有另外的過濾器。 |

### 語言

| 需求 | 現況 |
|---|---|
| 多語言、在地化提示詞 | ✅ 九種完整語言（語音、提示詞、控制台、App、通知）。繁體中文經過真實通話驗證，其他語言經過模擬通話驗證。 |
| 偵測語言、通話中切換 | ✅ 開場依來電號碼和 SIM 卡決定；通話中 AI 跟著對方換語言。用 28 種語言的來電者模擬過。 |
| 雙卡、每張卡各自的語言 | ✅ 「各 SIM 卡的主要語言」。 |
| 逐字稿翻譯 | ✅ 其他語言的句子保留原文，附上翻成你通知語言的對照。 |
| 方言與口音 | 🟡 模型聽得懂多少就是多少；我們沒有另外調整。 |
| 來電者與真人之間的即時翻譯 | ❌ |

### 替你辦事

| 需求 | 現況 |
|---|---|
| 替你撥出電話 | ✅ AI 代打：即時字幕、向你提問（`ask_owner`）、通話中交代、結構化結果、接續再打。模擬驗證過，等待真手機的回報。 |
| 預約時間 | ✅ AI 記下請求但不當場答應；你在「待處理事項」或 Telegram 卡片上同意或不同意；對方透過簡訊或 AI 回電收到答覆。 |
| 行事曆 | ✅ 一鍵加入 Google、Outlook.com、Microsoft 365、Apple、Yahoo 或 `.ics`，不用連任何行事曆帳號。 |
| 簡訊回覆 | ✅ 預約答覆從接這通電話的 SIM 卡用簡訊發出。收到的簡訊可以用簡訊轉發器轉出去。 |
| 通訊錄 | ✅ 從 vCard、CSV、TSV、純文字、Excel、Word 匯入，PDF 和圖片交給 Gemini；合併重複；匯出 vCard。 |
| 通話中使用工具 | 🟡 `propose_appointment` 與 `ask_owner`，各自受嚴格的狀態機管控。刻意不開放任意工具。 |
| 通話摘要、意圖、待辦 | ✅ 四行摘要，預約變成待處理事項。沒有情緒分析或統計儀表板。 |

## 接下來值得做的

大致依「投入換到的效益」排序：

1. **真實使用的回報**：AI 代打在真手機上撥出、其他手機型號、其他語言、Telegram 以外的通知管道。這比任何新功能都重要。
2. **來電記憶**：除了聯絡人名字和備註，把同一個號碼最近幾次的摘要放進提示詞。
3. **依號碼的規則**：一定大聲通知的 VIP、絕不陪聊的號碼、特定聯絡人用不同的提示詞。
4. **營業時間**：時間外改用不同提示詞或播一段語音。
5. **手機回報更清楚的通話狀態**：撥出電話被接起的那一刻就回報，讓待處理事項和代打頁面不用靠聽人聲，就能分辨「接通」和「還在響」。
6. **從手機 App 轉接／三方通話**，讓真人可以接手。
7. **同一套通話邏輯換用其他即時模型**（OpenAI Realtime，以及逐漸成熟的本機語音對語音模型）。
8. **移除舊的選單式程式路徑**，讓主程式更好讀。
9. **macOS 與 Windows 的簽章、公證發行版**。
