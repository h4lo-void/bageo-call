# 發展藍圖

相對於大家對開源電話接聽系統的期待，這個專案目前做到哪裡，以及接下來值得做什麼。這裡沒有任何一項是承諾；歡迎提 pull request。

## 這個專案的不同之處

大多數開源的接待系統都需要 SIP 線路或雲端電話服務帳號。這個專案接的是**你本來就有的那張 SIM 卡**，用你桌上的一支手機，搭配語音對語音（speech-to-speech）模型——所以不用租號碼，延遲和插話處理都由模型本身負責，而不是靠語音轉文字、LLM、文字轉語音一路串接起來。

## 社群想要的功能——目前狀態

| 需求 | 狀態 |
|---|---|
| 全天候接聽、自由對話而不是選單 | ✅ |
| 低延遲 | ✅ 語音對語音；手機還在響時就先準備好開場白。 |
| 真正的打斷（barge-in） | ✅ 在通話錄音裡不含 AI 自己聲音的手機上（我們實際使用的 Pixel 9）；其他手機上，AI 會先把句子講完。 |
| 沉默處理 | ✅ 先問對方還在不在，然後結束通話。 |
| 語音活動偵測、雜訊 | ✅ 用 Gemini 的，或本機的偵測器。 |
| 語言偵測、通話中切換 | 🟡 選用的「用對方的語言回答」；依賴模型本身。 |
| 多種語言、在地化的提示詞 | 🟡 九種語言；只有繁體中文在真實通話中驗證過。 |
| 方言與口音 | 🟡 模型聽得懂什麼就是什麼；我們沒有另外調校。 |
| 垃圾電話／自動語音電話處理 | ✅ 拒接號碼；推銷和詐騙電話用關鍵字偵測，然後婉拒或陪聊拖時間。 |
| 依知識庫回答、不亂編 | 🟡 「AI 可以回答的資料」——放在提示詞裡的純文字，加上一條「不要猜」的規則。沒有文件搜尋。 |
| 來電者記憶（認得再次打來的人） | ❌ |
| 通話後摘要、意圖、待辦 | ✅ 四行。沒有情緒分析或統計儀表板。 |
| 行事曆 | 🟡 附「加入行事曆」連結／`.ics` 的建議；可選擇自動加入 Google 日曆。AI **不會**在通話中預約時間。 |
| 通知、簡訊／電子郵件摘要 | ✅ 十六種管道類型，包含電子郵件。不會發送簡訊。 |
| Webhook、n8n / Zapier | ✅ 每個事件一個 JSON webhook；其他的用 REST API。 |
| 描述你的業務、自動完成設定 | 🟡 訪談提示詞，在任何聊天 AI 裡執行。 |
| AI 身分揭露、錄音告知 | 🟡 「AI 助理」方式內建揭露；「本人」方式在被問到時強制揭露。錄音告知要靠你的提示詞。 |
| 抵抗提示詞注入 | 🟡 每份提示詞裡都有一條固定規則；沒有另外的過濾器。 |
| 自備金鑰、沒有按分鐘計費的平台費 | ✅ |
| 所有東西都存在自己的機器上 | ✅ 除了送給模型和通知服務的部分。 |
| 網頁控制台 | ✅ |
| 一步啟動 | ✅ Windows / macOS / Linux 的啟動腳本；Docker 映像檔。 |
| REST API | ✅ — MCP ❌ |
| 營業時間、假日 | ❌（簡單的情況可以用狀態留言處理） |
| VIP 號碼直接轉給真人 | ❌ |
| 附摘要轉接給真人 | ❌ 手機 App 目前還不能橋接通話。 |
| 來電者與真人之間的即時翻譯 | ❌ |
| 緊急關鍵字處理 | ❌ |
| 花費上限、每日通話數限制 | ❌ 只有最長通話時間的設定；請到你的 API 供應商那裡設定預算。 |
| 完全本機的語音堆疊（Whisper / Ollama / Piper） | ❌ 受支援的模式下沒有。程式碼裡有一條較舊的管線，但無人維護。摘要已經可以使用本機模型。 |
| SIP / Asterisk / FreeSWITCH | ❌ 不是目標——但手機通訊協定很小而且有文件，所以可以用 SIP 前端來代替手機。 |
| 多租戶、白牌 | ❌ 沒有規劃。 |
| CRM 整合 | ❌ 請用 webhook。 |

## 值得做的下一步

大致依「花的功夫能換到多少用處」排序：

1. **其他手機和其他語言的回報**——哪些能用、哪些不能。這比任何功能都重要。
2. **依號碼設定規則**：為已知來電者加上名字和備註（「這是我媽媽」）、一定會大聲通知的 VIP、永遠不陪聊拖時間的號碼。
3. **來電者記憶**：把同一個號碼最近幾次的摘要放進提示詞。
4. **營業時間**：非營業時間改用另一份提示詞，或播放一段語音。
5. **通話中使用工具**（Gemini function calling）：查行事曆、查訂單。需要謹慎——能行動的 AI，也可能做錯事。
6. **通話轉接／多方通話**：由手機 App 來做，讓真人可以接手。
7. **其他即時模型**：接在同一套通話邏輯後面（OpenAI Realtime，以及日漸成熟的本機語音對語音模型）。
8. **移除較舊的選單式程式路徑**，讓主程式更容易讀。
9. **經過簽章與公證的發行版**（macOS 與 Windows）。
