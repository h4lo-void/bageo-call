# 發展藍圖

Bageo 1.6 這套開源 AI 電話助理已經做到哪些、哪些只做到一部分，以及接下來值得做什麼。這裡沒有任何承諾或時程；歡迎發 pull request。

## Bageo 跟其他 AI 總機哪裡不一樣

大多數開源 AI 總機都需要 SIP 線路或雲端電話帳號。Bageo 接的是**你本來就有的 SIM 卡**，插在你桌上一支已 root 的 Android 手機裡，搭配語音對語音模型（Gemini Live）：不用另外租號碼，回話快、能被插話靠的是模型本身，不是語音轉文字、LLM、文字轉語音串成的一條鏈。從 1.0 開始，同一支手機也能用你自己的門號替你打電話。

## 1.6 的現況

**已完成**：現在就能用。**部分**：能用，限制寫在說明欄。**還沒有**：尚未實作，沒有時程。

## 接下來值得做的

大致依「投入換到的效益」排序：

1. **真實使用的回報**：AI 代打在真手機上撥出、其他手機型號、其他語言、Telegram 以外的通知管道。這比任何新功能都重要。
2. **來電記憶**：除了聯絡人名字和備註，把同一個號碼最近幾次的摘要放進提示詞。
3. **依號碼的規則**：一定大聲通知的白名單號碼、絕不陪聊的號碼、特定聯絡人用不同的提示詞。
4. **營業時間**：時間外改用不同提示詞或播一段語音。
5. **手機回報更清楚的通話狀態**：撥出的電話被接起的那一刻就回報，讓「待處理事項」和代打頁面不用靠聽人聲，就能分辨「接通」和「還在響」。
6. **完善通話轉接與三方通話**，讓試驗中的急事三方通話更穩定，並加上附語音摘要的暖轉接。
7. **同一套通話邏輯換用其他即時模型**（OpenAI Realtime，以及逐漸成熟的本機語音對語音模型）。
8. **移除舊的選單式程式路徑**，讓 Bageo 的程式碼更好讀。
9. **macOS 與 Windows 的簽章、公證發行版**。
